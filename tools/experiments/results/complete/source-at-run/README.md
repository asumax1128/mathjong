# 実行時のソース

plan.json のsourcesに記録した5ファイルを、計測完了時にSHA-256を照合して保存したもの（.txt）。別ディレクトリ用の実行可能パッケージではない。

計測後にtrio-complete-plan.mjsの採用閾値ちょうどの丸め誤差を整数の交差積比較に修正した。実データから選択と全ジョブを再計算し、修正前後で変化していないことをvalidate-trio-complete.mjsで検証済み。AI・ゲームの判断はこの修正では変わらない。元のコードもここに保存し、修正前の失敗テストログを親ディレクトリに保持した。

現在のコードで再実行する場合は空の新規ディレクトリへ出力する。既存計測のplan.jsonを書き換えて新しいコードで実行したように見せない。

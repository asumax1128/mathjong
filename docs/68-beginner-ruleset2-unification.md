## 実装
- `src/ui/beginner-practice.js`：
  - 全課題を `PRACTICE_RULESET`（＝`CURRENT_RULESET`＝2）で作る。課題ごとの版の指定（`ruleset`）は削除した。旧ルールの課題はない。
  - 和了の精算を通常対局と同じにした：`createMatch` の宣言料5点（供託）＋`applyRoundResult(..., { riichi })`。結果画面に宣言料と供託の獲得を表示する。持ち点の合計は400点。
  - 現行ルールの王牌・ドラを、卓の情報（ドラ表示牌 → ドラ）と結果の内訳に表示する。内訳には通常和了の1点・役（リーチを含む）・ドラを出し、合計＝和了点。
  - 8-A のフリテンの案内：
    - リーチ後に見送った → 「この局はもうロンできない（ツモは可）」
    - 見送った（リーチ前） → 「自分の次のツモまでロンできない」
    - 和了の牌を捨てた → 「捨て牌のフリテン」
  - 待ち・フリテンの欄（通常対局と同じ `waits-view`）を、聴牌の局面がある 7-D・5-A・5-B・8-A にも表示する。
- 8段階の構成・進み具合（`mj-beginner-room-v2`、版1の引き継ぎ）は変更なし。
- 旧ルールの対局再現（`newrules` なし・`=1` の再現URL、`Game` の ruleset 0・1）は削除しない（エンジン・再現のコードは変更なし）。

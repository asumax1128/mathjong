# 公式ライブラリ・過去のルール案（将来構想）

最終整理: 2026-10-24。現行3枚面子方式に**これらの式を混ぜているわけではない**。途中で検討した数式麻雀のアイデアを、後日再開できるように保存する。

## 1. 企画の発端と変遷

### 初期構想: 数学全般の公式が「役」
展開・因数分解、三角関数、指数・対数、数列、微積分などから、数学的に正しい等式を牌で構成する。多くの公式で共通する牌（数字、変数、+、−等）を保持することで、狙う公式を切り替える読み合いを目指した。

**懸念**: 数学分野間で共通しない専用牌が増え、誰も和了できなくなる。特に文字・数字・括弧を完全に分割すると1式の必要枚数が多すぎる。

### 完成パーツ型（旧A案）
`sinα`、`cosβ`、`sin²θ` などを複合牌とし、少ない枚数で加法定理や倍角公式を作る。

**長所**: 公式が少ない牌で完成し、他人の待ちが推理しやすい。**短所**: 複合牌の種類が多く、有名角の数値構築には不向き。

### 記号組立型（旧B案）
`sin`、`cos`、`π`、`2`、`3`、`6` 等から角度・値を構成。弧度法で角度の多様性を確保する案。

**長所**: パーツの汎用性と角度の計算が学習になる。**短所**: 分数を組み立てるだけで多数の牌が必要になり、牌数が膨張。

### 過渡的ハイブリッド
頻出の角度や式のみ複合牌とし、残りは基本記号で構成する。数字や演算子は共有牌、`×` は省略、`=` を数値牌にくっつける、などを検討。

### 現行試作への転換
角度は度数法で管理し、`sin` + `30°` + `=1/2` のような**正しい値の3枚組**を基本面子とする方式に一本化。3面子による通常和了と、9角度牌の特殊和了を検討。

この転換により、**三角関数の恒等式を直接作る役と、面子同士の関係で得点が付く役は異なる仕組み**である。現行方式で恒等式役を採用するには、追加設計が必要。

## 2. 将来の公式ファミリー

### A. 三角比の基本・相互関係
- `tan θ = sin θ / cos θ`
- `sin² θ + cos² θ = 1`
- `1 + tan² θ = 1 / cos² θ`
- `sin(90°−θ) = cos θ`
- `cos(90°−θ) = sin θ`
- `sin(180°−θ) = sin θ`
- `cos(180°−θ) = −cos θ`
- `tan(180°−θ) = −tan θ`

### B. 加法・減法定理
- `sin(α+β) = sinα cosβ + cosα sinβ`
- `sin(α−β) = sinα cosβ − cosα sinβ`
- `cos(α+β) = cosα cosβ − sinα sinβ`
- `cos(α−β) = cosα cosβ + sinα sinβ`
- `tan(α+β) = (tanα+tanβ)/(1−tanα tanβ)`
- `tan(α−β) = (tanα−tanβ)/(1+tanα tanβ)`

### C. 倍角・半角・三倍角
- `sin 2θ = 2 sinθ cosθ`
- `cos 2θ = cos²θ − sin²θ = 2cos²θ−1 = 1−2sin²θ`
- `tan 2θ = 2tanθ/(1−tan²θ)`
- `sin²(θ/2) = (1−cosθ)/2`
- `cos²(θ/2) = (1+cosθ)/2`
- `tan²(θ/2) = (1−cosθ)/(1+cosθ)`
- `sin 3θ = 3sinθ−4sin³θ`
- `cos 3θ = 4cos³θ−3cosθ`

### D. 積和・和積・三角関数の合成
- `sinα cosβ = [sin(α+β)+sin(α−β)]/2`
- `cosα cosβ = [cos(α+β)+cos(α−β)]/2`
- `sinα sinβ = [cos(α−β)−cos(α+β)]/2`
- `sin A+sin B = 2sin((A+B)/2)cos((A−B)/2)`
- `cos A+cos B = 2cos((A+B)/2)cos((A−B)/2)`
- `a sinθ+b cosθ = R sin(θ+φ)`（`R=√(a²+b²)`、位相 φ は係数により定義）

### E. 三角形で使う公式
- 正弦定理: `a/sin A = b/sin B = c/sin C = 2R`
- 余弦定理: `a²=b²+c²−2bc cos A`
- 面積: `S=bc sin A/2`

### F. 発展
- 周期性: `sin(θ+2π)=sinθ`、`cos(θ+2π)=cosθ`、`tan(θ+π)=tanθ`
- Euler: `e^(iθ)=cosθ+i sinθ`
- de Moivre: `(cosθ+i sinθ)^n=cos(nθ)+i sin(nθ)`
- 微分: `(sin x)'=cos x`、`(cos x)'=−sin x`

※記号中の割り算・負号等は数学的な定義域条件に従う。公式ファミリーの一部は高校外の発展内容を含む。

## 3. 共通パーツの設計候補
- `sin²θ`/`cos²θ`: 基本恒等式、余弦2倍角、半角の変形
- `sinθ`/`cosθ`: 相互関係、正弦倍角、余角
- `sinαcosβ`/`cosαsinβ`: 加法定理と積和公式を接続
- `sin(α±β)`/`cos(α±β)`: 加法定理、積和、和積を接続
- 数字 `1`/`2`、`+`/`−`: 多数の公式で使用

**複合牌は原則として複数の公式で再利用できるときだけ採用する**。1文字ずつ分割する案と、完成済み式を1枚にする案は、和了速度と汎用性のトレードオフ。

## 4. 将来開発時の注意
1. 現行の通常和了（3枚面子×3）は**「三角関数の値を知っているか」**を扱う仕組み。加法定理の丸ごとの等式を手牌で作る仕組みではない。
2. 一般公式を直接組むモードを導入するなら、**各公式の必要牌数、固定手牌数、牌の頻出度、等号の扱い**を再設計する。
3. 同じ基本公式の移項・書き換えは、別の高得点役に水増しせず、同じ役の別完成形として扱う方針が有力。
4. 学習効果だけでなく、複数待ち、分岐、危険牌の読み、実力差が成立するかを評価する。

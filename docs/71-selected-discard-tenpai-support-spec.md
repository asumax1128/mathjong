# 数雀｜選択牌の打牌後プレビュー（聴牌サポート）正式仕様 v1

状態：**仕様確定・実装未着手**。2026-11-01。オーナー承認済み：「選んだ牌を捨てるとどうなるか」を示す形式。既存UIの二度タップ打牌を維持する。

## 目的と固定事項
- 初心者が自分で捨て牌を選び、選択した結果を確認した上で確定打牌する。**自動打牌・全候補の正解順位表示をしない**。
- あおとの**「できるだけ鳴く」方針、鳴き確率、40%の雑打牌、その他12人のAIを一切変更しない**。PR #65の研究案Cは本番不採用で保持。
- 現行ruleset2、聴牌、役、フリテン、リーチ・5点供託・四家立直・アガリやめの判定を変更しない。
- 通常対局が対象。初心者の部屋や卒業試験、牌譜・復元の表示への適用は別PRで検討。
- 本人の手牌、公開の河・公開面子・ドラ表示牌、本人が既に知るリーチ待ちだけで計算。他家の手牌・未来の山を参照しない。

## 既存実装と重複禁止
`src/ui/waits-view.js` の `tenpaiWaitsView(rules,view,{selected,riichiWaits,myTurn})` は、本人の番に **選択牌を捨てた後の待ち** を計算し、各待ちの `winnable` と公開情報からの `unseen` を返す。これを再利用する。既存の待ち牌表示・ヒントUIの機能を削らない。同ファイル内 `null` は「待ちがない」または「未選択」に使われており、表示側で局面条件を明確に分ける。

## 操作・表示の契約
1. 自分の通常打牌ターン、合法な手牌を**1回タップ＝選択**すると、既存の打牌後の待ち表示と同じ選択IDを使って「この牌を捨てると」の説明を表示。選択後の待ちが有る場合は「この牌なら聴牌になります／聴牌を維持できます」のいずれかを、選択前の8枚だけからは単純判定できないため**同ターンに聴牌を保つ打牌が存在する場合に限り「維持」**と表現する。厳密には「打牌後は聴牌」表示を基本とし、事前にテンパイを持続していたかを誤って断言しない。
2. 選択後に待ちが無い場合は「この牌を捨てると聴牌しません」。**同じ局面で別の合法打牌に聴牌待ちが有ると判定できる場合のみ**「別の牌なら聴牌を保てます／聴牌にできます」と表示。そうでない場合「ほかの牌を選ぶと結果が変わるか考えてみよう」等、嘘のない表現とする。
3. 役が付く待ちと役なしの待ちを区別する。フリテンはロンの可否のみとしツモ可否と混同しない。公開情報上の `unseen` は **「自分から見えていない枚数（山にある枚数ではない）」** と注記。0枚でも聴牌の形を否定しない。役・フリテンの実際の判定方法は現行エンジンと一致させる。既存ヘルパーが足りなければ表示専用の純関数を最小追加し、エンジン判定やゲーム状態は変えない。
4. **未選択**：新しい判定テキストは表示しない。**選択変更**：即座に更新。**同じ牌を2回タップ**：既存どおり打牌し、プレビューは次状態にクリア。**長押しの並べ替え、スクロール、二段階操作**を破壊しない。
5. 自分の番以外、リーチ後の自動ツモ切り、ロン・ツモ・ポン・チーの意思決定中、結果画面では、打牌後プレビューの誤表示をしない。既存のリーチ時の待ち表示は保持。宣言できる牌のガイドとの矛盾・重複を避ける。
6. 「選ぶと確定してしまう」ような誤操作を増やさず、**牌選択のみ**で実行せず、候補ハイライトは既存スタイルに沿わせる。

## 表示の初期スコープと設定
- 第1版は既存ヒント領域の中に小さな補足行として入れる（モーダル、全牌への一括色分け、卓の上の大型オーバーレイを作らない）。スマホ縦でヒント・操作バーを隠さない。
- **既存のヒント設定と整合させる**。OFF/標準/詳しくという新しい三段切替は、既存の設定体系を現物確認して必要なら後続PRにする。初期版で新しい保存キーや設定UIを無断追加しない。
- 表示の確定文例：
  - 「この牌を捨てると聴牌です」
  - 「この牌を捨てると聴牌にはなりません」
  - 「待ち牌：○○（自分から見えていない牌：N枚）」
  - 「和了の形ですが、役がありません」
  - 「フリテンのためロンできません（ツモは別判定）」
- 固定で「正解」「不正解」「必ず和了できる」「山にN枚ある」とは言わない。

## テスト・非機能要件
- 単体：数学ⅠⅡ、役あり／役なし聴牌、フリテン、待ち0枚、選択変更、非法ID・未選択、同種別物理ID、鳴いた手、門前、リーチ、局進行クリア。

- 情報公平性：他家非公開手牌と未来山の入替で表示結果同一。表示のための対局状態変更なし。全体の通常テストとCIを成功させる。
- パフォーマンス：全候補の評価は選択した牌のプレビューと比較用の最小限に制限。iPhone Safariで選択反応を実機確認。操作遅延・タッチの二重確定を防ぐ。

## 受入基準
- 牌を1回タップすると**選択牌を捨てた場合の聴牌状態**が読める。別牌に切り替えると表示が更新され、2回目タップで通常どおり打牌。
- 聴牌でないときに「聴牌維持」と誤らない。役なし／フリテン／見えていない枚数を正しく区別。
- あおとと他AIの挙動・勝率を一切変えない。通常の対局進行を破壊しない。
- 適切なヒント位置とスマホでの可読性。旧データ・牌譜互換維持。

# 数雀｜オンライン対戦 段階4「入口の公開」メモと公開後の確認手順

設計の正本は [docs/79](79-online-play-design.md)〜[docs/82](82-online-stage3-reconnect.md)。

前提として、次の2つは所有者が実施済みで、監査側がライブで確かめている。

- 本番 Firebase（asumath-games）へのルール（`games/mathjong`）の適用
- `games/mathjong/config` の `{ enabled: true }`

## 1. 変更点

- **`ONLINE_PUBLIC = true`**（`src/ui/online-config.js`）
  - タイトルの「オンライン対戦」の入口を、公開サイトを含むすべてのタイトルに出す（`src/ui/app.js` の `ONLINE_ENTRY = true`）。
  - 接続先は `FB_CONFIG`（本番 asumath-games）。
  - オンラインの部品と Firebase SDK は、段階1どおり**入口を押したときだけ**読み込む。タイトル・通常対局・初心者の部屋・牌譜には影響しない。
  - 読込に失敗した場合は、オンラインの画面に「読み込めませんでした」と出すだけ。
- **停止スイッチは本番でもそのまま効く。**
  - 入口を押すと、匿名認証の後に `games/mathjong/config` を読む。
  - `enabled` が `true` でなければ（読めない場合を含む）「オンライン対戦は現在お休み中です」と出し、先へ進ませない。
  - **止めたいときは、Firebase Console で `games/mathjong/config/enabled` を `false` にする。**
- **版の確認（`meta.appVersion`）も本番でそのまま効く。** 部屋の版と自分の版が違えば入室させず、「ページを再読み込みしてください」と案内する。
- **ローカル開発の `?online=emu` は従来どおり使える。**
  - ローカル開発環境で `?online=emu` を付けると、Auth・Database エミュレータ（demo- プロジェクト）に接続する。
  - 公開ホストでは、この引数を無視する。
  - 試験用の引数（`?onlineCpuDelay=` など）も、ローカルだけで効く。
- エンジン（`src/engine`）は変更していない。試験の目的で本番のデータに書き込むことはしていない。

## 2. 試験の更新

- `tests/e2e/online-lobby.mjs` の「入口」の2件を、段階4の内容に合わせた。
  1. **ローカルのタイトル**：入口が出る。押すまで SDK を読まない。
  2. **公開サイト相当のホスト（`mathjong.test`）**：
     - 入口が出る。
     - 押すと、SDK を読み込み、**本番（asumath-games）の匿名認証へ向かう**（API キーで確認）。
     - エミュレータへは向かわない（`?online=emu` は無視される）。
     - 試験では、本番への要求をブラウザの中で止めるため、本番には接続しない。画面は「読み込めませんでした」になる。
- 停止スイッチ（`enabled:false`）で「お休み中」になり先へ進めないことは、エミュレータで従来どおり確かめている（同じファイルの「1」）。
- そのほかのエミュレータの試験は、変更せずにそのまま合格している：ルール試験・SDK 結合・1局戦・切断と復帰・4人4局戦と再戦。

## 3. オーナーの公開後の確認手順（iPhone）

公開 URL：https://asumax1128.github.io/mathjong/

**準備**：iPhone 2台を用意する（または、1台の Safari の通常タブと**プライベート**タブ。プライベートタブは別の匿名 uid になる）。

1. **入口**
   - 両方で公開 URL を開き、タイトルに「オンライン対戦」があることを確かめる。
   - 表示が古いときは、再読み込みする。
2. **ニックネーム**
   - 「オンライン対戦」を押し、ニックネーム（1〜10文字）を入れて「決定」を押す。
   - 「お休み中」と出た場合は、`config.enabled` が `true` か確かめる。
3. **部屋を作る（1台目）**
   - 数学Ⅰ・1局戦を選んで「部屋を作る」を押す。
   - 6文字の部屋コードが出る。
4. **部屋に入る（2台目）**
   - 「部屋に入る」にコードを入れて「入る」を押す。
   - 両方のロビーに2人の名前が出ることを確かめる。
5. **CPU の選択（1台目）**
   - 空席の CPU を1人選ぶ（もう1人は「自動」のまま）。
   - 2台目の表示にも反映されることを確かめる。
6. **開始（1台目）**
   - 「開始」を押すと、両方が卓の画面になる。
   - 画面上部の帯に「○○の番 残り◯秒」が出ることを確かめる。
7. **1局打つ**
   - 自分の番は、牌を2回タップして捨てる。
   - ロン・ポン・チーが出たら選ぶか、見送る。
   - 他人の番や宣言の待ちでは「宣言を待っています…」などと出る。
8. **局の結果**
   - 両方に同じ結果（点数）が出る。
   - 「次の局へ」→ 最終結果へ進み、**両方の持ち点と順位が一致**することを確かめる。
9. **（任意）切断と復帰**
   - 対局中に2台目の Safari のタブを閉じ、約10秒待つ。1台目に「（代打ち）」が出る。
   - 2台目で公開 URL を開き直して「オンライン対戦」を押すと、自分の席に戻る。
10. **（任意）ホストの再読み込み**
    - 1台目を再読み込みすると、2台目に「ホストの復帰を待っています（残り◯秒）」が出る。
    - 1台目で「オンライン対戦」を押すと、続きから再開する。
11. **（任意）再戦**
    - 最終結果で2台目が「もう一戦」を押し、1台目が「もう一戦（ロビーへ・1人が参加）」を押す。
    - 両方がロビーに戻る。
12. **後片づけ**
    - 最終結果の「部屋を出る」を押す（ホストが出ると部屋は消える）。
    - 残った部屋も、12時間で期限切れになる。

**うまくいかないときに記録してほしいこと**：

- 端末と iOS の版
- 手順の番号
- 画面の文言（「読み込めませんでした」「版が違う」「お休み中」など）
- タイトル下の「画面 v…」の表記

緊急に止めるときは、Console で `games/mathjong/config/enabled` を `false` にする。進行中の対局はそのまま続くが、入口から新しく入ること（切断後の入り直しを含む）はできなくなる。

# 決定事項と保留事項のログ

最終更新: 2026-10-24

## 明確に採用する方向が決まったもの
- 数学の公式・三角関数から、**数学の知識で勝敗に差が出る麻雀風ゲーム**を設計する。
- 最初の試作は三角関数の有名角の値を使用。
- 関数牌（sin/cos/tan）＋角度牌＋結果牌（=1/2 等）で**3枚1組**。
- 独立した = 牌／等号リーチは取りやめる。
- × 牌は不要。関数や数字の掛け算は省略表記で扱う構想。
- 第3・第4象限の角度も使用する。
- **4人対戦**が基本。
- **チー（上家から）とロン**を追加し、ポンはなし。
- **チーすると役がないと和了できない**。門前は役なし和了可という比較モデル。
- 第n象限のみで3組を揃える役を採用候補に追加。
- 0°,30°,45°,60°,90°,120°,135°,150°,180°の**9種類を集める特殊役**を採用候補に追加。通常の3面子とは別完成形とする。
- 同じ3面子を揃えるなど、麻雀の役満に相当する希少役を検討。

## 試験済みだが正式確定していないもの
- 関数牌は各12枚→各16枚に増やした試験を実施。山156枚 vs 168枚。
- 角度牌各4枚、結果牌各4枚。
- 手持ち8枚、和了9枚（3面子）。
- 九角無双という役名と点数。
- 4つのAI戦略、仮採点、チーのAI判断。
- 「三関制覇」などの名称と得点。

## 保留・明確にユーザーが迷っているもの
- **360°の採用**: sin/cos/tanの値は0°と同じ。数学的周期性・表裏九角の対称性という利点がある一方、角度の冗長性もある。採否は未決定。
- **裏九角無双**（180°〜360°の9種類）は助手からの提案段階。
- 役満候補の採用条件と点数、鳴き可否。
- 通常の麻雀の親、点棒、流局、リーチ、フリテン、複数ロン。
- 戦略運比率（目標は運およそ30%・実力およそ70%、未検証）。
- 第1〜第4象限を使った追加の役、同値三連の格付け。
- 将来の一般公式モード（平方公式、加法定理、半角、積和、指数等）を現在の3枚セットとどう統合するか。

## 企画の経緯（時系列）
1. 「三角関数の公式が役になる麻雀」を発想。
2. 数字・文字・演算子・等号による汎用的な数式麻雀も検討。
3. 公式の多さと共通牌の使いやすさから三角関数へ再集中。
4. 複合牌 vs 分割牌を比較。弧度法で角度を作る案も出た。
5. 度数法、0〜180°の9角度へ絞る提案。
6. =1/2 等の結果牌に一本化し、3枚で三角セットを作る方式に移行。
7. 第3・第4象限を追加、4人対戦・チー・ロン、鳴いたら役必須。
8. 象限一色、三重同式、九角無双などの役・特殊和了を検討。
9. 360°の是非と関数牌各12/16枚の配分を比較。
10. GitHub asumax1128/mathjong で企画資料の保管を開始。

**過去の提案をすべて「決定」と解釈しない。** 変更時にはこのログとルール・牌・役・実験記録を一緒に更新する。
## Ver.0.1 実装のための暫定採用（2026-10-24）
以下は Web 試作版を動かすための**暫定採用**であり、正式決定ではない。詳細は [Ver.0.1 実装記録](10-ver0.1-implementation.md)。

- 得点は和了者への加算のみ（点棒授受なし）。

## 実装
### 判定（`src/ui/discard-preview.js` の `discardPreview()`・純関数）
- 入力：自分の `view`（`Game.viewFor(0)`：自分の手牌・全員の河・公開面子・ドラ表示牌）、選んだ牌の id、捨てられる牌の id（画面の `humanDiscardFilter` と同じ）、自分だけが知る情報（自分の捨て牌の種類＝エンジンの `discarded`・同巡の見逃し＝`tempFuriten`）。**他家の手牌・山の並び・未来の牌は使わない。対局の状態は変えない。**
- 待ち：既存の `tenpaiWaitsView(rules, view, { selected, myTurn: true })` をそのまま使う（エンジンの `waitsOf` と同じ「和了の形」、役の有無は `analyzeWin(…, { ron: true, closed })`、見えていない枚数は `unseenFromView`）。
- 表示しない：未選択・手牌にない id・捨てられない牌・自分の通常の打牌番でない（他家の番、ロン／ポン／チーの判断中）・リーチ中・結果画面などのモーダル表示中・卒業試験（docs/71 で別PR）。
- 聴牌のとき：
  - `yaku`：待ちのうち役があって和了できるものが全部（all）／一部（some）／ない（none）。
  - `furiten`（ruleset 2 だけ）：捨てた後の捨て牌の種類（これまでの捨て牌＋選んだ牌）に待ちがある（discard）か、同巡の見逃しが続く（temporary：鳴いた後の打牌など。自分の通常ツモで解除）。ロンだけ不可（ツモは別判定）。
- 聴牌にならないとき：`others`＝ほかの捨てられる牌（種類ごとに1枚だけ調べ、見つかった時点で終了）で聴牌になるものがあるか。**どの牌かは返さない・表示しない。**

### 表示（ヒント欄の中の補足行）
- 位置：`.study-dock`（「ヒント・数式確認」）の見出しの下。ヒント OFF のときは案内文の代わり、ヒント ON のときはヒントの内容の上。ヒント欄の大きさは変えず、あふれたら欄の中でスクロール。モーダル・卓の上の表示・全ての牌の色分けは作らない。
- 文言（docs/71 の確定文例）：
  - 聴牌：「この牌を捨てると聴牌です」＋「待ち牌：［牌］（自分から見えていない牌：N枚）」（待ちごと）＋「※見えていない牌の数は、山に残っている数ではありません（他家の手牌にある場合もあります）」
  - 役なし：「和了の形ですが、役がありません」（一部だけなら「一部の待ちは和了の形ですが、役がありません」）。待ちの牌に「役なし」の印
  - フリテン：「フリテンのためロンできません（ツモは別判定）」。捨て牌にある待ちに「捨て牌」の印
  - 聴牌にならない：「この牌を捨てると聴牌にはなりません」＋「別の牌なら聴牌にできます」または「どの牌を捨てても、まだ聴牌にはなりません」
  - 「正解」「不正解」「必ず和了できる」「山に N 枚ある」とは言わない。「聴牌を維持」とも言わない（打牌前の手が聴牌だったかを断言しないため、「捨てると聴牌です」を基本にする）。
- 文字と色を併用（「聴牌」「聴牌ではない」の文字の札）。`role="status"`・`aria-live="polite"`。
- 既存の手牌の上の「捨てると待ち」・フリテンの行、リーチの印・宣言牌の選択、2回タップの打牌、長押しの並べ替えはそのまま。

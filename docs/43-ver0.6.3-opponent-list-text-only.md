# 数雀 Ver.0.6.3｜対戦相手一覧から仮画像を除去（2026-10-29）

## オーナーの指示と背景

Ver.0.6.2のiPhone Safariスクリーンショットを確認。追加3人のカードに頭文字「ゆ／た／の」と「仮表示」が割り込み、名前・難易度・特徴の配置が不揃いになり見にくい。オーナーの正式指示は **「この、仮表示の部分があると見にくいので、なくす。もしイラストを今後追加しても、スマホ版は詳細を見ないとイラストは見られないようにして」**。

## 正式仕様

- 12人の**一覧カードは全端末でテキストのみ**。名前・難易度バッジ・特徴・選択チェックを従来順（初級4→中級4→上級4）で表示。頭文字枠・「仮表示」・未完成画像の告知は**一覧にも詳細にも出さない**。画像の有無でカードの高さが不揃いにならないこと。
- **将来のイラスト画像は、少なくともスマホではカードをタップして詳細を開いたときに限り閲覧できる**。さらに実装上はPCも含め、一覧では画像要素をDOMに生成しない。正式画像を採用した後、`src/ui/opponents.js` の `PROFILES[id].artSrc` に静的で信頼できる画像パスを追加すれば、`src/ui/app.js` の `oppDetailHTML` が詳細パネル内だけに `<img>` を遅延生成する。画面の画像サイズはレスポンシブ・`object-fit: contain`、`loading=lazy`。この変更で**画像ファイルは新規に追加しない**。今後の正式画像採用には別の承認・確認を必要とする。
- 詳細では年齢・難易度・性格・打ち筋・選択・解除をこれまで通り表示。カードタップと選択チェックは別動作のまま。
- 既存9名＋新3名のAI実装、内部ID、ゲームルール、牌、スコア、保存、PRNG、初心者の部屋、再現URLは無変更。エンジン版0.5.0-aを維持する。画面版は0.6.3。

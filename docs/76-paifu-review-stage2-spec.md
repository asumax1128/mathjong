# 数雀｜牌譜振り返りモード 第2段階・正式実装仕様

2026-11-02。第1段階 PR #69 は main 統合済み、オーナー iPhone Safari 実機7/7合格で正式受入。第2段階は**保存された通常対局の牌譜を安全に振り返る画面**を追加する。戦績の累積集計は第3段階の別PR。

## 固定・非対象
- 最新 main を基点に独立した Draft 実装PR。旧研究PR/旧牌譜PR #37を取り込まない。PR #69保存形式 schemaVersion 2、IndexedDBと既存保存APIを保持。
- 数学Ⅰ/Ⅱ、1/4/8局、現行ruleset2の通常対局を対象。保存完了/途中退出/未精算/破損/非対応を取り違えない。
- 通常対局のAI12人、ルール、RNG、精算、点数、聴牌サポート、既存URL、保存キーを変更しない。記録や振り返りによる再戦・行動再実行を本体ゲームへ反映しない。
- **自分以外の手牌・未来の山・非公開牌を振り返りUIへ表示しない。** private-fullデータは検証用隔離モジュール内でのみ扱い、UIへ渡すのは座席本人の手牌＋各時点の公開情報（河、副露、局、親、点数、宣言、ドラ表示、合法な終局結果）を最小限に射影した値のみ。序盤の画面へ後の情報を出さない。
- この段階では推奨打牌、危険度、最善手、AI内部情報、全員手牌公開、共有URL/JSONダウンロード、戦績集計は作らない。対局中の秘密を画面へ見せない。

## 画面構成
1. タイトルから「牌譜／振り返り」へ。端末保存・送信なしを明記。IndexedDBが利用不可、0件、破損/非対応の件数も安全に案内。
2. 一覧：日時、数学Ⅰ/Ⅱ、1/4/8局、4席の相手、自分の順位/最終点（完走した場合）、完走／中断／記録途中の状態を区別。index metadataだけで描画し、全牌譜の一括ロードは禁止。
3. 一件選択：loadPrivate→既存decode/verifyで検証、成功したものだけ再生UIへ。再生不能な場合は理由を表示し通常対局へ影響させない。大容量/大量データの表示は逐次/上限を設ける。
4. 対局→局→時点：前の判断/次の判断を操作し、現在の行動者、打牌/鳴き/見送り/リーチ/和了・精算、公開卓、自分の手牌、持ち点/供託を当該時点のみ表示。相手の未公開手牌は裏向き枚数のみ。再生中は行動しない。特に副露後/暗カン/フリテン/四家立直/連荘/リーチ宣言5点・供託返還、途中記録最後の有効prefixを区別する。
5. 前後ボタン、局選択、先頭・末尾、一覧/タイトルへ戻る。iPhone縦390/375/320pxで判読、横スクロール・誤打牌・既存卓への影響なし。タップ領域、選択状態、アクセシビリティを考慮。**閲覧画面にゲームの打牌操作バーを出さない。**
6. 個別削除を加えるなら利用者の明示確認・トークンCAS・削除競合対応を確保。初期版は既存の全件削除動作を維持し、個別削除は別PRでも可。削除された履歴を再び保存したり、レビュー画面が削除世代を変更してはならない。

## 再生APIと安全の契約
- `src/engine/paifu.js` の `replayPaifuRound` 等を精査。private全文を`app.js`のグローバル状態やHTMLのdata属性、console、URL、sessionStorage、localStorageへコピーせず、**映像用射影の純関数/専用モジュール**を作る。JSONで非公開牌を不用意にシリアライズしない。
- 正常な牌譜でも対局終了後のみ過去の自分の手牌と公開情報を表示。時点ごとの自己視点を復元し、次の手の情報は見せない。鳴き・待ち・和了の判定を偽らない。
- 初期版は牌譜検証済みのデータだけを再生対象とする。保存時の完全性検証と読込時の検証を省略しない。旧schemaやrulesetには誤って新規rulesetを当てず、未対応として説明。
- 記録途中/中断牌譜は **実在する検証済みの局/判断までだけ**を再生。結果未確定なら「未精算・中断」と明示。
- 画面表示の失敗、例外、Worker不可・保存DB不可・削除競合時でも通常対局起動・進行を妨げない。レビューUIは必要時の動的ロードを優先し、失敗時に安全に元画面へ戻す。
- 大局数、長い連荘、端末低速時に主スレッドを長時間停止させない。情報射影・再生は計算量を測る。読み込み中キャンセル/旧画面への遅延描画を防ぐ。

## テスト・品質ゲート
- 牌譜記録→保存→読込→1判断ずつ前後→局切替→精算までのE2E。数学ⅠⅡ、1/4/8局、途中退出/流局/ロン/ツモ/リーチ/ポン/チー/暗カン/フリテン/四家立直など固定fixture。
- 各時点の表示を `Game.viewFor(humanSeat)` の公開情報・自分の手牌と独立比較。他家の秘密牌・未来の山・AI内部情報の非表示をDOM/画面/URL/console/アプリ状態の境界で検証。自分の席が0以外のケースも想定し、保存設定を正とする。
- 破損、旧版、途中記録、外部タブで削除、容量上限、オフライン/IndexedDB不可、二度開き、読み込み中の戻る、端末回転、iPhone縦320/375/390/430px。
- 全既存npm test、全体E2E、CI、牌譜保存回帰、12AI、聴牌サポート/2回タップ/長押し。各ステップでPR固定HEADのCodex独立監査（P0-P3）→ディレクター判断→既存PagesのiPhone Safariオーナー受入。
- E2Eの複数タブ待機不安定・ブラウザ外からDBを全消去した場合のepoch ABAは既知課題として維持。隠して「全検証成功」としない。定期監視・自動購読は作らない。

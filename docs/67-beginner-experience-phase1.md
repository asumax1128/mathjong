## 2. 新しいカリキュラム（操作中心・8段階）
1. **数式の作り方**：3枚の数式 → 9枚を3つの面子に。
2. **捨て牌の判断**：ツモと打牌 → 実戦形式「捨てる牌を選ぶ」。完成した面子・あと1枚の組をくずす牌は止め、理由を出す。
3. **聴牌と待ち牌**：実戦形式「聴牌を作る」（牌を1回タップすると、その牌を捨てた後の待ちが表示される。聴牌にならない牌は止める）→ 待ち牌クイズ（8枚の聴牌の手から待ちをすべて選ぶ。正解はエンジンの和了判定）。
4. **リーチ**：金色のボタン・聴牌になる牌の印・牌を選ぶと待ち・宣言料5点。リーチ後はツモ切りだけ。
5. **ロン・ツモ**：従来の課題。
6. **フリテン**：
   - 6-A 捨て牌のフリテン：自分が捨てた 30° が待ちに入る。150° ではロンできず、理由を表示する。30° のツモなら和了できる。
   - 6-B 見逃しのフリテン：30° を見送ると、150° ではロンできない（同巡）。自分のツモで解除され、30° でロンできる。
7. **鳴き（チー・ポン）**：従来の4課題。
8. **卒業試験**：
   - 8-A 仕上げの練習：従来の固定局面。
   - 8-B **卒業試験（1局戦）**：通常の対局画面で、初級の既定3人（かなた・みつき・あおと）と1局戦を打つ。現行ルール（宣言料・フリテン・待ちの表示）で、数学Ⅰ・Ⅱのどちらでも受けられる。

- 実戦形式の課題は、すべて実エンジン（`Game`・`rules`・`match`）を使う。新しい課題は現行ルール（ruleset 2：フリテン・待ちの表示・王牌）。鳴きの課題は関数牌のポンを含むので、従来の版（0）のまま。
- 待ち・フリテンの欄は、通常対局と同じ `src/ui/waits-view.js` と `Game.furitenOf`（公開情報と自分の手牌だけ）を使う。二重実装はしない。
- 卒業試験の合否：1局戦を最後まで打てば修了（順位に関係なく合格）。1位なら「1位で合格」。固定局面の課題だけで実力が付いたとは扱わず、本番と同じ1局戦を卒業の条件にした。何度でも受け直せる。記録は回数・1位の回数・最高順位・最後の順位・モード。
- 最終結果に卒業試験の結果を表示し、「初心者の部屋へ戻る」ボタンを置く。「同じ3人と再戦」も卒業試験として扱う。

## 4. 通常対局のリーチ支援
- **リーチできるとき**、「リーチ」ボタンを金色で強調し、ゆっくり光らせる。視覚演出「簡易」・端末の「動きを減らす」設定では光らせない（色の強調は残す）。
- ボタンに「宣言料5点」と書く（現行ルール。宣言料のない過去の版の再現では書かない）。
- **聴牌になる捨て牌**（`riichiOptions`）に金の点線の枠を付ける。エンジンの選択肢と一致する。
- 「リーチ」を押した後：
  - 状態欄は「リーチ：金の印の牌を選ぶと待ちを表示」。
  - 牌を選ぶと、手牌の上に「捨てると待ち」と待ち牌・残り枚数が出る（既存の待ち表示）。状態欄は「待ちを確認して『リーチして捨てる』」に変わる。
  - 確定ボタンは「リーチして捨てる／宣言料5点を供託へ」。
  - 聴牌にならない牌は選べない。選ぶまで確定できない。自動で打牌はしない。
- 宣言後は従来どおり、名札の持ち点 −5 と卓の中央の供託（PR #54）で示す。

# あおと改善案の比較研究（研究専用・判定なし）

> 状態：**研究専用 Draft PR**（ブランチ `research/aoto-improvement-variants`。PR #64 の研究ブランチの上に作成）。**本番の AI・エンジン・UI は変更しない**（CI で `src/` と `index.html` に main との差分がないことを確認）。mainマージ・Pages公開はしない。**統計的な採用判断はこの PR では行わない**。数値の評価は Codex の独立評価に委ねる。

## 背景（PR #64・docs/69）
あおとの敗因：
- 役のない鳴き：鳴いた手の聴牌の 77〜85% が役なし。
- 40% の雑な打牌：聴牌を保つ打牌の選択率は 44〜48%。

反実仮想「鳴かない」「雑な打牌なし」で、どちらも 1位率が上がった。今回は、あおとの個性（鳴き好き・雑さ）を残す改善案を比べる道具を作る。

## 4つの条件（`tools/research-aoto-variants.mjs`）
本番のあおとの判断（`decideCharacter`）を先に求め、その後で研究用の規則で差し替える。乱数の使い方は本番と同じで、差し替えたときだけ行動が変わる。

| 条件 | 内容 |
|---|---|
| **A** | 現行（本番の判断そのまま）。差し替えのない試合と完全一致することをテストで確認 |
| **B** | 役を狙える鳴きだけ許可。下の「B の規則」を参照 |
| **C** | 聴牌を維持する打牌を優先し、それ以外の雑さは保持。下の「C の規則」を参照 |
| **D** | B と C の併用 |

**B の規則**
- 本番がポン・チーを選んだとき、鳴いた後の局面に、鳴いた手でも成立する役（門前限定・特殊和了を除く）の候補が「あと `maxMissing` 枚以内」（既定2枚、`--max-missing` で変更可）で残る場合だけ鳴く。残らなければ見送る。
- 役候補は既存の `yakuhint.yakuCandidates`（宣言の後の局面を評価する `claim` 経路）を使う。
- 鳴く確率（ポン 85%・チー 75%）は本番のまま。

**C の規則**
- 本番の打牌（40% の雑な打牌を含む）が、聴牌になる捨て牌があるのに聴牌を崩すときだけ差し替える。差し替え先は、聴牌になる捨て牌のうち、自分から見えていない残り枚数（公開情報）が最も多いもの。
- 聴牌にならない局面の打牌は本番のまま（雑さを保持する）。
- リーチの宣言は本番と同じ `riichiDecision`（初級）。

### 情報の公平性
- B・C が使う情報：自分の手牌・公開面子・全員の河・ドラ表示牌（`viewFor`）、エンジンの `riichiOptions` / `waitsOf`（自分の手牌）、`yakuCandidates`（公開情報）。
- 他家の手牌・山の並び・未来の牌は使わない。テストで、他家の手牌と山を入れ替えても判断が同じことを確認した（B 20件以上・C 500件以上の局面）。

## シミュレーション
- 現行ルール（ruleset 2・宣言料5点・四家立直・アガリやめ）、数学Ⅰ・Ⅱ × 1局・4局・8局戦。
- 実験：

  | 実験 | 内容 |
  |---|---|
  | E1 | 初級AI 4人（あおとだけ条件で差し替え）。同じ seed・親で席を4通りに回す |
  | E2 | 初心者代理（基本・スマート）＋あおとを含む初級AI 3人。同じ seed・親・相手・席 |

  4条件は同じ seed・席で行うので、試合ごとに対応する。
- サンプル数（scale 1）：

  | 実験 | 1局戦 | 4局戦 | 8局戦 |
  |---|---|---|---|
  | E1 | 60 seed × 4席 | 20 × 4 | 10 × 4 |
  | E2 | 48 seed × 代理2版 | 16 × 2 | 8 × 2 |

  条件ごと・モードごとに数える。`--scale` で全体の倍率を変える。
- 出力（JSON）：条件ごと・セルごとに次をまとめる。
  - PR #64 と同じ行動別の集計（分母は合法な選択機会・95% 区間）
  - 差し替えの回数（B：鳴きの検討・見送り、C：打牌の確認・差し替え）
  - 条件A との試合ごとの対応差（あおと・初心者代理の順位差・点差の平均。記述のみ）
- 保存：`docs/data/aoto-variants/result-scale1.json`（scale 1・seed0 700001）。**数値の解釈・採用判断は行わない。**

## 再現性・テスト（`tests/research-aoto-variants.test.js`）
- 同じ seed で4条件とも完全一致。seed を変えれば変わる。計画の範囲（数学Ⅰ・Ⅱ × 1/4/8局戦）。
- 条件A は、差し替えのない本番の試合と完全一致する（数学Ⅰ・Ⅱ × 1/4/8局戦）。
- B の規則：
  - 固定局面で、三関制覇があと1枚のチーは許可、役が3枚以上遠いチーは見送り。
  - 本番がチーを選ぶ乱数でも見送る。
  - C 単独では鳴きは変わらない。
- C の規則：
  - 固定局面で、聴牌を崩す打牌は残り枚数の多い聴牌打牌に差し替える。
  - すでに聴牌を保つ打牌、聴牌にならない局面はそのまま。
- 情報の公平性（上記）。
- 研究の実行後も本番の係数（`BEGINNER_PARAMS`）は同じ。
- 全条件・全セルの完走（400点・供託0は試合ごとに検査）と、JSON の形。
  - 差し替えの回数の整合：A は0、B は打牌を変えない、C は鳴きを変えない、C・D の聴牌を保つ率は 100%。
  - JSON に採用判断の記述を含めない。
- CI（`.github/workflows/research-aoto-variants.yml`）：
  - 上のテストを実行する。
  - 同じ seed で2回実行し、ハッシュの一致を確かめる。
  - `src/`・`index.html` に main との差分がないことを確かめる。
  - 結果を artifact に保存する。公開・デプロイはしない。

## Codex の独立評価で確認してほしい点（提案）
- B の基準「あと2枚以内」の妥当性（1・3・制限なしとの比較は `--max-missing` で可能）。役候補の評価が鳴いた後の局面として正しいか。
- C の差し替え先（残り枚数が最多）の選び方が、あおとの個性（雑さ）を損なっていないか。差し替えの頻度は JSON の `stats` を参照。
- ペア比較の設計（同じ seed・席・親）と、席ごとの乱数列による対応の妥当性。
- 採用の基準：
  - 初心者代理の1位率・4位率・平均順位
  - あおとと他の初級AIの差
  - 流局率・1局の手番数
  - 1局戦と4/8局戦の違い

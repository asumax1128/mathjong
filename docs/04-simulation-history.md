# シミュレーション履歴（2026-10-24 時点）

この記録は会話内で報告した試験結果を保存するためのものである。**数値の再現性、AIの実装、ルールの不完全性を区別する。**

## 1. 使用モデル・限界
- 4人が同じ山から引く。初期8枚、9枚で和了。
- 上家から正しい3枚組のチー可、全他家からロン可、ツモ可。
- 門前は役なし和了可、鳴き後は役必須。
- AI戦略の名称: 速攻型、役重視型、門前重視型、バランス型。
- 初期のシミュレーターでは他家の危険牌読み・点棒支払い・フリテン・複数ロン・最適役満追跡は未実装。
- 平均「捨て牌数」は**4人合計**であって各自の巡目ではない。
- 確率・勝率は実装した簡易AIに依存し、熟練プレイヤーの勝率とは異なる。
- 360°を含む17角度、tan90°/270°は未定義。結果牌13種類。

## 3. 過去の実験（会話中の報告記録）
- 1人ツモ捨て／9角度／関数各12枚等の初期モデル: 25巡以内の戦略あり和了率45.8%（240試行）、ランダム捨て1.3%（1,500試行）。4人対戦と直接比較不可。
- 9角度 vs 17角度の小規模比較: 約45% vs 約46%（各200試行）。試行数が少なく、角度を増やした分だけ山も増加。
- 4人対戦・チー有無の初期比較: 250試行ずつ。チーの存在で和了の頻度・決着速度が大きく変わると報告。ただしAIとルールが後期モデルと異なる。
- チー時役必須の初期比較: 各400局、計1,200局。三関制覇に成立役が偏ったと報告。
- 4タイプAI混合: 500局。速攻130勝、役重視110勝、門前154勝、バランス106勝。平均捨て牌数28.1。現行2,500局比較を優先参照する。

これら初期値は過去の報告を保存したもので、最新版コードに基づく完全な再計算が済んだことを保証しない。

## 4. 九角無双の試算（別モデル）
角度9種類を集め続ける単独試算を10万回実施したと会話で報告。20ツモ以内0.235%、25ツモ以内0.809%など。ただし4人の他家・途中和了・チー/ロンを反映しない別条件。4人戦での成立確率として利用しない。

## 5. 今後の検証
1. 360°あり／なしを、**山の総数も揃える条件**と自然な山でそれぞれ比較。
2. 関数12/16/20枚を共通乱数・席順ローテーションで比較。
3. 九角無双・三重同式・同角三関などを**積極的に狙う専用AI**で出現率評価。
4. チー・ロン・フリテン・複数ロン・ドラ/点棒などの仕様確定。
5. 速度のみならず**通算得点・放銃率・戦略間勝率**で比較。
6. バグ検査、ランダムシード、バージョン情報、ソースの保存を含む再現性の整備。

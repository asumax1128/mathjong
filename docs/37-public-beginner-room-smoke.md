# 初心者の部屋：公開URLの第1〜6段階E2E

## 目的と実行

通常対局の入口を検査する `tools/public-smoke.mjs` とは別に、既存E2Eの初心者教材検査を**同じコードのまま実際のURLへ接続**して実行する。

```sh
node tests/e2e/play.mjs --public-url https://asumax1128.github.io/mathjong/ --only v07BeginnerRoom,v07BeginnerRoom2 --shots /tmp/public-beginner-shots
```

先に画像保存先を作る。PlaywrightとChromiumが必要。専用の `.github/workflows/public-beginner-room.yml` がインストールと保存先作成を行い、`page_build`、`workflow_dispatch`で実行する。未公開の12人UIを現在の公開サイトへ要求する偽失敗を避けるため、公開検査をPRでは起動しない。PRの回帰は既存のローカルE2Eワークフローで検査する。新サイトやプレビューを作らず、既存Pagesを使う。

## 検査範囲

- 第1〜3段階の正解・誤答・ヒント・通常画面への帰還。
- 第4段階の上家だけのチー・他家のポン・鳴いた直後の打牌・役なしロン不可・役ありロン。
- 第5段階の合法なリーチ・ツモ切り・ロン・ツモ。5-Cは牌選択前後ともツモだけを表示し、精算後は `[108,98,98,96]`。
- 第6段階の聴牌を崩した場合の案内、やり直し、リーチ、ロン見送り後のツモ、卒業表示、400点保存。
- 第1〜6段階のクリア保存、リロード後の途中課題再開、一覧・未開放段階・クリア後の再挑戦、保存例外。
- 320/375/390/430pxのタッチ相当操作、横スクロールなし、卒業後のキャラクター選択から通常対局の開始まで。
- ページ例外・HTTP 4xx/5xx・資源取得失敗。直接URLのページ取得はHTTP 200を要求する。

## 実行モードの区別

- 従来のコマンドは従来どおり、ローカルサーバーを起動し `mathjong.test` を転送して検査する。
- `--public-url` 指定時はローカルサーバーを起動せず、リクエストを横取り・転送しない。外部URLでは環境のHTTP(S)プロキシ設定を使い、TLS検証を無効化しない。
- 公開モードはDOM操作だけの `v07BeginnerRoom` / `v07BeginnerRoom2` に限定する。テストフック依存の他の検査や、引数なしの全体実行は拒否する。
- URLの認証情報・query・fragment・HTTP(S)以外のschemeは拒否する。接続失敗時にローカルへ代替しない。
- 実行ログの対象URLを必ず記録する。同じモードをローカルHTTPで検証しても、実際のPagesの成功とは扱わない。

# Ver.0.7 公開後UI改善①：実況削除と席ごとの牌の向き

2026-10-29のオーナー指示に基づく軽微なUI修正。基準はPR #34マージ後のmain `1603bdf3da18f93737eb6ec52813b6d6ea616eff`。PR #34はGitHubでMerged（2026-10-29 08:18:52 UTC）を確認した。公開版はオーナーから公開済みと報告されているが、この実行環境から実URLへ接続すると403となるため、今回の変更の公開確認とは区別する。

## 変更

- 対局中の実況行と、その文字列生成を削除。ゲームイベントや音・カットインは削除しない。
- 上部はロゴ・ガイド・設定のみ。数学モード・局名・連荘・残り山・親は卓中央に集約。ガイドと設定は44px以上の高さを確保。
- 自分の牌は従来の向き。上家は90°、下家は−90°、対面は180°。他家の河と公開面子の牌全体を回転し、枠に回転後の実寸を確保する。リーチ宣言牌はその席の向きからさらに90°。他家の裏向き手牌も左右席では横長にする。
- 他家の公開面子は河と同じ小牌サイズへ統一（820px未満は22×30px、820px以上は26×35px。回転前の寸法）。面子の背景・取得牌印・発光対象は維持。自分の手牌・公開面子、結果画面の公開面子は縮小しない。
- 他家の卓の余分な伸長、隙間、パディングを抑え、河は独立スクロール。自分の手牌、2回タップ、長押し、操作バーは従来の処理。
- 縦画面のヒントは手牌下、タブレット横の62/38、低い横画面の卓内スクロールは維持。横画面を禁止するオーバーレイは追加しない。
- ヒントの内容・2段階・回数・色枠、エンジン、12人AI、ルール、得点、PRNG、保存形式、再現URL、初心者の部屋、正式画像、音声レシピは変更しない。ドラなし。Ver.0.8未着手。画面版は引き続き0.7.0-a。

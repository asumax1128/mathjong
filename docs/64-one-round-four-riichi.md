## A. 1局戦
- タイトルの「対局の長さ」：**1局戦（東1局のみ）／4局戦（東1〜東4局）／8局戦（東1〜南4局）**。既定は従来どおり4局戦。選択は従来の保存キー `mj-length` に `1` として保存する（`4`・`8` の保存値はそのまま有効、それ以外は4局戦）。
  - 3つを横に並べ、説明は名前の下に置く（タイトル画面の高さは従来より 44px 低い。320px 幅でも文字は切れない）。
- 1局戦は東1局の1回だけ。**親が和了しても連荘しない**。和了（ロン・ツモ、親・子）・山切れの流局・数学Ⅱの24回の流局・四家立直のどれでも、その1局で試合終了（`endReason: 'normal'`）。
- 開始は各100点・合計400点。精算（親子の倍率）・ドラ・暗カン・フリテン・AI は4局戦と同じ。終局時の得点で順位（同点は同順位）。
- 結果画面：「1局戦はこの1局で終わりです（親の和了でも連荘しません）。試合終了です。」→「最終結果へ」。
- 最終結果：実施した局数「1局（1局戦・東1局のみ）」（連荘回数の行は出さない）、各局の結果、「同じ3人と再戦」（1局戦・同じ3人・全員100点・現行ルール）、「相手を変更」（選択画面 → 1局戦のまま）、「タイトルへ戻る」。
- 再現URL：`len=1` を受け付ける（ゲームが出力する URL も `len=1`）。1局戦にない局状態（`hand` 1以上・`renchan` 1以上・`round` 2以上）はエラー画面（別の局面として黙って始めない）。`len` の 1・4・8 以外はエラー。従来形式の URL（`hand` なし）は従来どおり。
- AI：キャラクター AI の判断係数は変更なし。試合の情報（`length: 1, hand: 0`）は従来の式のまま渡る（1局戦の東1局は「最終の親番」として扱われる）。
- 4局戦・8局戦の親の連荘・親交代・順位・精算・通し局数の上限は変更なし。

## B. 四家立直（ruleset 2）
- 4人全員のリーチが成立したら**途中流局**。AI と人を区別しない（エンジンの `riichi[]` で判定）。
- 判定の時期：4人目のリーチ宣言牌に対する**ロンの判断がすべて終わってから**（`_advance`、次のツモに進む直前）。
  - ロンが成立すれば和了（ロンが優先、四家立直にしない）。複数人がロンできるときは従来どおり打牌者に近い順（アタマハネ）。
  - 全員が見送った、またはフリテンでロンの選択肢がなかった → 四家立直の途中流局。
  - 4人目の宣言牌が山の最後の牌の後でも、四家立直を先に判定する（どちらも点数の移動はない）。
- 点数の移動なし（リーチの宣言料も0のまま）。試合の扱いは流局と同じ：1局戦は終了、4局戦・8局戦は親交代して次の局。
- 記録：`result = { type: 'draw', reason: 'four-riichi' }`、記録 `events` の最後は `{ type: 'abortive-draw', reason: 'four-riichi' }`。山切れ・24回の流局は従来の形（`{ type: 'draw' }`・`exhaustive-draw`）のまま。試合の記録 `log` にも `reason` を残す。
- 画面：結果画面の見出し「途中流局 四家立直」と説明（4人目の宣言牌でロンはなかった・得点の移動なし・宣言料なし）。最終結果の「各局の結果」に「途中流局（四家立直）」と表示し、「流局」と区別する（1局戦は開いた状態、複数の局は閉じた見出しに「四家立直N回」）。ガイドのルールにも説明。
- 旧ルール（ruleset 0・1、過去の再現URL `newrules` なし・`=1`）には入れない：4人がリーチしても従来どおり続行する。

## 実装
- `src/engine/game.js`：`fourRiichiRule = ruleset >= 2`。`_advance(from)` の先頭で4人のリーチを判定し `_endDraw('four-riichi')`。ロンは `respond`／`_openClaims` で先に確定するのでここに来ない（＝ロン優先）。
- `src/engine/match.js`：`MATCH_LENGTHS = [1, 4, 8]`。1局戦は `dealerKeeps = false`（親の和了でも連荘しない）→ 親番が1つ進んで `hand >= length` で終了。流局の記録に `reason`。
- `src/ui/replay.js`：`REPLAY_LENGTHS = [1, 4, 8]`、1局戦の局状態の検査。
- `src/ui/app.js`・`styles.css`：タイトルの3択、保存値、結果画面（四家立直・1局戦の終了）、最終結果（局数の表示・各局の結果）、ガイド。
- `tools/simulate-ruleset.mjs`：`--length 1|4|8`、四家立直の件数（`drawFourRiichi`）と4人リーチ後の和了（`allRiichiWin`）、1局戦の終了・4人リーチのまま続行しないことの検査。

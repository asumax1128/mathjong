**公開予定URL：https://asumax1128.github.io/mathjong/**

### Pages の設定手順（オーナーが1回だけ行う）
1. GitHub で `asumax1128/mathjong` を開き、**Settings** → 左メニュー **Pages**。
2. **Build and deployment** の **Source** を **Deploy from a branch** にする。
3. **Branch** を **`main`**、フォルダーを **`/ (root)`** にして **Save**。
4. 1〜数分後、同じ画面の上部に「Your site is live at https://asumax1128.github.io/mathjong/」と表示されれば公開完了。
   進行状況はリポジトリの **Actions** タブの「pages build and deployment」で確認できる。
5. `main` が更新されると数分で自動的に再公開される。

## 2. 操作方法
- **打牌**：牌をタップすると持ち上がる（選択）→ もう一度タップ、または右下の「捨てる」。別の牌をタップすると選択が移る。
- 右端に少し離れて表示される牌が **ツモ牌**。
- **ツモ／ロン**：和了できるときだけ赤いボタンが出る。ロンは「ロンしない」で見送れる。
- **チー**：上家（左下の席）の打牌で面子ができるときだけ、青い「チー sin 30° = 1/2」形式のボタンが出る。「見送る」で見送れる。
- **ヒント**：完成面子の数とあと1枚の組合せ数を表示（使用回数は結果画面に記録）。
- **⚙（設定）**：AI の速さ、現在の seed・局番号、得点リセット。
- 結果画面：完成した数式・役・点数・累計点・全員の手牌・**再現情報（seed と局番号）**。「次の局へ」で次局（親が移動）。

## 3. 最初に確認してほしいこと
1. URL を開いて対局画面が出る（黒画面・読み込み失敗がない）。
2. 縦向きで、横スクロールせずに全体が見える。手牌8〜9枚がタップしやすい。
3. 牌を選択すると持ち上がり、選択中であることが分かる。素早く2回タップしても**拡大表示されず**打牌される。
4. `1/√2`・`−√3/2`・`−1/√3` などの結果牌が読める（手牌・河の小さい牌の両方）。
5. 下部の操作ボタンが、アドレスバーやホームインジケーターに隠れない（スクロール後も）。
6. 下の固定 seed で、チー・ロン・ツモのボタンが出て、押す／見送るの両方で進行する。
7. 結果画面の内容が読めて、「次の局へ」で正常に再開する。3局以上続けて遊ぶ。

### 公開前に iPhone で試す（同じ Wi-Fi の PC を使う）
1. PC でリポジトリのフォルダーを開き、`node tools/serve.mjs 8080 --base /mathjong/ --lan` を実行。
2. 表示された `http://<PCのIPアドレス>:8080/mathjong/` を iPhone の Safari で開く。
3. 終わったら PC で Ctrl+C を押して停止する（`--lan` なしで起動するとこの PC からしか開けない）。
- 配信されるのはゲームのファイル（`index.html` と `src/` の JS・CSS）だけ。`.git` や資料は配信されない。
- この方法は `localhost` ではないため、公開サイトと同じくテスト用機能は無効。

## 4. 固定 seed（ブラウザ自動テストで確認済み）
**毎回、右端のツモ牌を捨て、チー・ロンはすべて見送る**と、次の場面が必ず再現する。

公開後のURL（未公開の間は上の LAN の URL の末尾に `?seed=…` を付ける）：

| URL | 起きること |
| --- | --- |
| `https://asumax1128.github.io/mathjong/?seed=1` | 自分の1巡目の打牌の後、上家の打牌で**チー**ボタン |
| `https://asumax1128.github.io/mathjong/?seed=111` | 自分の1巡目の打牌の後、他家の打牌で**ロン**ボタン |
| `https://asumax1128.github.io/mathjong/?seed=34` | 自分の2巡目のツモで**ツモ**ボタン |

- どこかでチー・ロン・ツモを実行したり、ツモ牌以外を捨てたりすると、その後の展開は変わる（AI は公開情報で判断するため）。
- `?seed=数字&round=n` で、その seed の**第n局の山・親から直接開始**できる（得点は0から）。
- 九角無双などの特殊和了は、通常の対局ではほぼ出ない。公開サイトには山を指定する機能を**意図的に入れていない**（不正操作防止）。確認はローカル環境の自動テストで実施済み。

## 5. 不具合を報告するとき
結果画面（または ⚙ 設定）の「再現情報」に表示される内容を必ず書く。

- 実施日、iPhone の機種、iOS のバージョン、Safari（またはアプリ名）
- URL（`?seed=…&round=…` 付き）と、何局目か
- 操作手順（例：「1巡目にツモ切り、2巡目に sin を選んで捨てる→…」）
- 期待した結果／実際の結果
- スクリーンショット（可能なら画面全体）

テンプレート：[docs/11 の「実機テスト報告テンプレート」](11-audit-and-device-testing.md#7-実機テスト報告テンプレート)

## 6. 区別
- **ブラウザ自動テスト**（Playwright・Chromium）：iPhone 等の画面サイズとタッチ操作を模擬したもの。Safari（WebKit）エンジンでの自動テストは開発環境に WebKit がないため**未実施**。
- **iPhone 実機テスト**：オーナーが行う。自動テストの代わりにはならない。

# 数雀｜初級AI・初心者敗因の行動別診断（Phase 2）

2026-10-31。PR #58のiPhone Safari 4/4項目合格を受けた研究。**公開AI係数・UI・エンジン・ゲームルールは一切変更しない**。

## 研究の問い
1. あおとが勝てない原因は、手牌効率・鳴き過多・聴牌到達率・リーチ不使用・和了点・放銃のどれか。
2. かなた・ゆうじん優勢がどの行動段階で生じるか。
3. 初心者代理モデルの負けはリーチの遅れ・リーチ候補の捨て牌選び・待ち枚数・ロン見逃し・無役鳴き・放銃・流局のどこか。
4. 1局戦と4/8局戦で原因は異なるか。数学Ⅰと数学Ⅱで差はあるか。

## 必須の計測設計
- AI4人それぞれ：参加局数、ツモ/ロン和了、役・ドラ・平均和了点、打牌数、リーチ可能機会、リーチ宣言、リーチ後和了率、ポン/チー発生率、聴牌での流局、振聴と無役待ち、放銃数、平均順位、1位・4位率。
- 初心者モデル：基本（リーチ低利用）・リーチ＋限定チー、聴牌到達時のリーチ未宣言、見えている待ち枚数、即和了選択の見逃し、フリテン・放銃・鳴き後無役、順位変化。
- 決定前の合法手と決定後の行動を記録し、選択率の分母（合法機会）を明示する。実際に実行可能な手しか計測しない。
- 公開情報のみで計算し、他家の手牌・山の未来・内部的正解情報をAI判断やヒントに使わない。診断に限り終了局の確定事実を集計可能。
- 共通seed/親位置/キャラ配置のペア比較。サンプル数の事前宣言、各条件の実行数、信頼区間、試行間ばらつき。単純な「AIの一位数/出場数」は相手構成依存と明記。
- 現行ruleset 2：リーチ宣言料5点、四家立直、アガリやめ、1/4/8局戦、400点保存、試合終了供託0。
- 現行AI・初心者代理モデルは変えない。実際の人間勝率を推定したと断言しない。

## 実装工程
1. 既存PR #48〜#50, #59〜#62の分析コードと現行AI実装を照合し、データ計測フックを整理する。
2. **研究用ツールだけ** `tools/research-beginner-loss-diagnostics.mjs` に追加する。研究用PRのAI係数変更をmainへ持ち込まない。
3. ログは `tools` 以下の再現可能な機械可読JSONとして出力し、GitHub Actionsのartifactに保存。CIは研究用のみで公開を行わない。
4. キャラ別の「勝てない理由」を行動→中間状態→結果の因果仮説に分ける（観察上の相関を因果と断定しない）。
5. 行動改善の案を**あおと単独、ゆうじん単独、かなた単独**に分け、リーチ利用率と待ち品質・流局率を必須評価軸に採用。
6. 十分な試験結果を確認してから別ブランチの実装PRを提案。現時点で係数の変更・実機テスト・Pages公開は不要。

### 問いへの答え（ログで支持されるもの／未検証を分ける）
1. **あおとは鳴きで手を進めているのか、和了しにくくなっているのか** — **両方。ただし差し引きは大きく不利（支持）。**
   - 鳴くと聴牌（形）には届く。鳴きなしの反実仮想で聴牌到達率が 53%→32〜34% に下がるので、鳴きは形を進めている。
   - しかし鳴いた手の聴牌の 77〜85% は役なしで、和了できない。鳴いた局の和了率は 4〜7%、門前は 19〜22%。リーチもできなくなる（機会の局 20%）。
   - 反実仮想（研究用・同じ seed）の4局戦 1位率（数学Ⅰ／Ⅱ）：

     | 条件 | 1位率 |
     |---|---|
     | 現行 | 6.5%／9.9% |
     | 鳴かない | 11.9%／13.3% |
     | 雑な打牌なし | 14.5%／15.1% |
     | 両方なし | **23.1%／23.9%** |

     両方なしで、みつき・ゆうじん並みになる。**敗因は「役のない鳴き」と「雑な打牌（40%）」の2つで、ほぼ同じ大きさ**（支持）。
   - 放銃率が最も高い（22〜24%）。役なしの鳴き手で降りずにツモ切りを続けるためと考えられる。降り判断がないことは仕様どおりだが、放銃との因果は**未検証**。
2. **あおとの聴牌率・リーチ率は低いか** — 聴牌到達率は**低くない**（53%、みつき・ゆうじんの 43〜49% より高い）。低いのは和了につながる聴牌（役なし）とリーチ。
   - リーチ機会のあった局は 20〜22%（他は 63〜71%）。7割の局で鳴いて門前でなくなるため。
   - 機会があっても宣言は 52〜57%。雑な打牌で聴牌を外す（聴牌を保つ打牌の選択率 44〜48%）。初級AI はリーチできる打牌を選べば必ず宣言する実装なので、宣言しない理由は打牌の選択（支持）。
3. **かなた・ゆうじんが勝つ理由** —
   - かなた：**和了回数**（和了率 38〜41%、平均和了点は他と同程度の 2.7〜2.8）。聴牌を保つ打牌 71〜75%・聴牌到達率 64〜66%・リーチ 91〜94% と、手を進める判断が最も強い（支持）。
   - ゆうじん：**和了点の高さ**（平均 3.4〜3.6。対々和・三暗刻の刻子系の役）。和了率は 23〜26% でみつきと同程度（支持）。
4. **初心者代理は聴牌してもリーチを使わないことで不利か** — **主因はリーチではなく「聴牌を保つ打牌」（支持）。**
   - 段階のペア比較（同じ seed・相手・席）で、聴牌を保つ（ダマ）vs 基本の順位差：
     - 数学Ⅰ：−0.23（1局）・−0.49（4局）・−0.61（8局）
     - 数学Ⅱ：−0.15（1局）・−0.54（4局）・−0.63（8局）
     - すべて95%区間が0をまたがない。
   - ＋リーチ vs ダマ：
     - 4・8局戦では点数が増える（数学Ⅰ 4局 +5.3点、8局 +11.4点。区間は正）。順位の改善は数学Ⅰ 4局戦だけ有意（−0.16）。
     - **1局戦では順位がやや悪化**（+0.10、両モードで有意）。仮説：1局戦は動かない人が100点で同点が多く、宣言料5点で同点の1位から落ちる（機構は**部分的に支持・個別の検証は未実施**）。
   - ＋チー（面子未公開時22%）：点数が下がる（数学Ⅰ 4局 −3.8・8局 −12.4。区間は負）。鳴いた局の和了率 3.5〜5.6%・鳴いた聴牌の役なし 76〜84% で、あおとと同じ構造（支持）。
5. **弱体化したAIで流局が増える原因** — **聴牌の遅れと減少（支持）。**
   - easy（既存研究PRの弱体化設定）の流局率：数学Ⅰ 12.6%（現行 2.0%）、数学Ⅱ 9.7%（同 2.0%）。
   - かなた・みつきの変化：聴牌を保つ打牌 71→32%、聴牌到達率 65→35%・47→27%、初聴牌の巡目 5.5→7.9。
   - 流局時の聴牌人数は 3.0→1.5、1局の手番数は 30→42〜46。数学Ⅰは山切れ、数学Ⅱは24回の上限で終わる。
   - あおとの鳴き率も上がる（72→86%）が、役なしなので流局を止めない。弱体化していないゆうじんが 1位率 57〜64% に偏る（支持）。

### 検証できなかった点
- 実際の人間の打ち方・勝率（代理モデルは仮定。リーチ・チーの割合や打牌の質は実測ではない）。
- あおとの放銃の原因：危険度を読まないことによるものか、聴牌を目指すツモ切りによるものか。放銃牌の内訳までは分けていない。
- 「役のある鳴きだけをする」あおとの反実仮想は未実施（今回は「鳴かない」だけ）。
- 1局戦でリーチが順位を下げる機構の直接の確認（同点の崩れの集計）。
- かなたの「あおとの河を読む」特徴の寄与（かなた単独の反実仮想は未実施）。
- 親・席の位置ごとの差、試合途中の点差に応じた行動の差（AI に渡す持ち点は局の開始時の値）。
- AI 係数の変更案の効果（今回は研究の診断だけで、改善案は試していない）。

### 次に検証すべき改善候補（優先順）
1. **あおと：役のある鳴きだけにする**（研究用の反実仮想で検証）。鳴きの個性を残したまま、役なし聴牌（77〜85%）を減らす。比較対象は今回の「鳴かない」「両方なし」。
2. **あおと：雑な打牌を「聴牌を崩さない範囲」に限る**。雑さ（40%）は残し、聴牌時だけ聴牌を保つ。今回の「雑な打牌なし」より小さい変更で、リーチ宣言（機会の局で 53%）を上げる。
3. **初心者支援（UI・教材）：聴牌を保つ打牌の支援を最優先**。初心者代理の改善は「聴牌を保つ」が最大（順位 −0.15〜−0.63）。
   - 既存の待ち表示・リーチ候補の印を、リーチしない場面（ダマ）でも分かるようにする案。
   - 1局戦ではリーチの宣言料5点による同点崩れを案内する案。
   - 役のない鳴きに注意を出す案。
4. **かなたの強さの確認**：1位率 38〜49% で突出。弱めるなら、流局を増やさない方法（聴牌を保つ選択は残し、待ちの選び方・リーチの時期などで調整）を研究条件で比較する。easy のように聴牌を保つ選択を弱めると、流局が 5〜6倍に増える。
5. **評価の手順**：同じ seed・席の回し方・初心者代理4版のペア比較を採用ゲートにする。確認する指標は、初心者代理の1位率・4位率・平均順位、あおとの差、流局率、1局の手番数。

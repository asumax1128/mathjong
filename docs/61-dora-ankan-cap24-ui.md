## 1. 新旧ルールの選択・有効化（実装前に決めた仕様）

| 項目 | 仕様 |
|---|---|
| 既定値 | **従来ルール**（保存値がない・不正・保存できない環境はすべて従来ルール）。新ルールへ自動で切り替わることはない。 |
| 選び方 | タイトル画面の「ルール」欄（従来ルール／新ルール。2択を横に並べ、数学モード・局数の欄は変えない）。設定画面にも同じ選択があり、モードと同じく**次の新しい対局から**反映する（対局中の局は変わらない）。 |
| 保存 | `localStorage` のキー `mj-rule-set`。値 `new` のときだけ新ルール、それ以外は従来ルール。選択を変えたときだけ保存する。 |
| 対局中の固定 | 試合の開始時に `S.matchSettings.newRules` に確定し、試合の途中・連荘・次の局では変えない。「同じ3人と再戦」は終了した試合と同じルール。「新しい対局」（設定画面）とタイトル→対局開始は、そのとき選ばれているルール。 |
| エンジン | 局の開始時に `new Game({ ..., newRules: S.matchSettings.newRules })`。従来ルールでは `newRules` を渡さない（`false`）ので、山・配牌・AI・乱数・イベントは main と同一。 |
| 再現 URL | 新ルールの対局だけ `&newrules=1` を付ける。値は `1` だけが有効（それ以外はエラー画面）。**付いていない URL は従来ルール**なので、既存の再現 URL・テスト・seed の再生は従来どおり。`?rules=legacy`（ローカル専用の Ver.0.2.1 互換）とは別の名前にした。旧規則（`rules=legacy`）では新ルールを有効にしない。 |
| 画面での識別 | 卓の中央の数学モードの表示に「新ルール」を付ける。選択画面・最終結果・再現情報にもルールを出す。従来ルールの卓の表示は変えない。 |

## 2. 表示と操作（新ルールの対局だけ。従来ルールの画面は変更なし）
- **ドラ表示**：卓の右下の角（Ver.0.7 で空いていた区画 `br`）に、公開されたドラ表示牌（上段「表示牌」）と、それによるドラ（下段「ドラ」）を並べる。最初は1枚、暗カンのたびに1枚ずつ、最大5枚。直前に増えた1枚は枠で示す。王牌・嶺上牌・再抽選で採用しなかった候補・他家の手牌・山は表示しない（画面は `viewFor` と同じ公開情報だけを使う）。
- **暗カン**：自分の手番（ツモ直後・リーチ前）に、エンジンの `pending().ankan` に選択肢があるときだけ、操作バーに「暗カン」を出す。押すと確認の段階（槓子にする種類のボタンに牌を表示、手牌の該当4枚を強調、「やめる」）に入り、種類のボタンで実行する。確認の段階では打牌できない。リーチ中・チー／ポン直後・旧ルールではボタンを出さない（エンジンも拒否する）。
- **槓子**：公開面子として4枚で表示（自分は手牌の右、他家は各席の角）。暗カンだけの手は門前のまま（名札の「門前」も維持）。
- **嶺上ツモ・カンドラ**：エンジンの記録の順（暗カン → 嶺上ツモ → カンドラ）で、操作バーの案内に「暗カン → 嶺上ツモ（カンドラ追加）」と示し、嶺上牌を手牌で区別する。AI の暗カンも同じ案内を、その AI の打牌までの間に出す。重いアニメーションは付けない。
- **数学Ⅱの残りツモ回数**：新ルールの数学Ⅱだけ、卓の中央に自分の残り通常ツモ回数（24 − 通常ツモ回数。親の最初のツモを含む。鳴き・嶺上ツモでは減らない）を出す。他家の残り回数は名札の説明（title）に出す。24回の上限で流局したときは、結果画面に理由を出す。
- **和了結果**：基本点・役・ドラの枚数・ドラ加点・合計。役満はドラ加点なし（明記）。精算（親子・合計400点）は従来のまま。
- **ヒント**：暗カンの槓子を公開面子として扱い、暗カンだけなら門前の役（三暗刻など）も候補に入れる。公開されたドラ表示牌は見えている牌として数える。ドラは役候補に出さず、別の行で「ドラは役ではない（和了時 +1点/枚）」と手牌・槓子のドラの枚数を示す。従来ルールのヒントは変えない。

## 3. 実装（変更したファイル）
- `src/ui/app.js`：ルールの選択（タイトル・設定・保存 `mj-rule-set`・`S.nextNewRules`・`S.matchSettings.newRules`）、局の開始で `newRules` を渡す、卓の中央の「新ルール」と残りツモ回数、ドラ表示（`doraHTML`、表示は `viewFor(0).doraIndicators` だけから作る）、暗カンのボタン・確認の段階（`S.ankanSelect`、`ankan`／`ankan-type`／`ankan-cancel`）、槓子の表示（`meld ankan`、他家の面子の枠は4枚分 `--mt:4`）、嶺上牌の印、AI の暗カンの案内、結果画面（槓子の印と4枚・ドラの行・役満はドラ加点なし・ドラ表示牌とドラ・24回の流局の理由）、最終結果・再現情報のルール、ヒント欄の槓子とドラの行、ガイドのルールに新ルールの説明（新ルールの対局だけ）。
- `src/ui/replay.js`：`newrules=1` の検証と出力（従来ルールの URL の文字列は従来と同じ）。
- `src/engine/yakuhint.js`・`src/ui/hintstate.js`（画面のヒント専用。AI・判定は使わない）：暗カンだけの手は門前、暗カンのある手に特殊和了の候補を出さない、公開されたドラ表示牌を見えている牌として数える、ヒントの更新キーにドラ表示牌。どれも view に `doraIndicators` があるとき（新ルール）だけ読み、旧ルールの view では読む項目も結果も従来と同じ（既存の「非公開情報にアクセスしない」テストはそのまま合格）。
- `src/ui/styles.css`：新ルールの要素だけのスタイル（ドラ表示は Ver.0.7 で空いていた卓の右下の区画 `br`）、他家の面子の枠の幅（4枚の槓子のときだけ広がる。3枚の面子は従来と同じ）、タイトルのルール欄（2択を横に並べる）。
- エンジン（①〜④）は変更していない。

## 5. 残る課題・注意
- 320×568 のタイトル画面は、ルール欄を足した分だけ「対戦相手を選ぶ」がスクロールの下になる（約48px。横に並べて高さを抑えた。390×844 以上は1画面に収まる）。
- 他家の残りツモ回数は名札の説明（title）だけで、画面には常時表示しない（狭い画面の名札の幅を保つため）。
- 暗カン・嶺上・カンドラの演出は案内の文字・印だけ（効果音・カットインなし）。
- スマホ横（高さ500px以下）で河が5行を超えると、ドラ表示は卓のスクロールの中で見える（従来の河と同じ）。
- iPhone Safari 実機での確認は未実施（Chromium のスマホ相当の画面で確認）。

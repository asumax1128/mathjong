## 1. 何が卓の形を妨げていたか（main と PR #36 の比較）
- main（PR #34）：他家3人を「対面パネル＋上家・下家パネル」の箱として上から積み、河はパネル内で折り返す横並び。卓中央の左右に箱を並べるため、**卓を囲む形ではなく縦に積む形**だった。河は小さなスクロール枠で、長くなると隠れる。
- PR #36：同じ箱の構造のまま牌を席の向きに回転して省スペース化。向きは正しくなるが、箱を積む構造は残る。
- 今回：箱を廃止し、**卓そのものを1つのグリッド**として組み直した。

## 2. 卓全体の構造
- 卓は 7列×6行の CSS グリッド（`.mj-table`）。中央の正方形（局情報と4人の名札）の四辺に4人の河、その外側に他家の裏向きの手牌、各席の**右手側の角**に公開面子（実際の卓・天鳳と同じ配置）。自分の手牌と公開面子は卓の下。
```
 [対面の面子] [ 対面の手牌（裏）            ] [下家の面子]
 [対面の面子] [ 対面の河（180°・6枚折り返し）] [下家の面子]
 [上][上家の河] [ 対面の名札 ][         ] [下家の河][下]
 [家][ 90° ]   [上家の名札 局情報 下家の名札] [ −90°  ][家]
 [手][      ]  [ 自分の名札                ] [       ][手]
 [上家の面子] [ 自分の河（6枚折り返し）      ] [        ]
 自分の手牌（左）＋公開面子（右）
 チー自動・ポン自動・自動整列・ヒント ……… ガイド・設定
 ヒント・数式確認（独立スクロール）
 操作バー（捨てる・ツモ・リーチ・チー・ポン・ロン・見送る）
```
- 席の位置はエンジンの席番号のまま：自分＝席0（下）、下家＝席1（右）、対面＝席2（上）、上家＝席3（左）。
- 河・公開面子・裏向きの手牌は、**その席の人から見た正しい向きのまとまり**を作り、まとまりごと回転する（自分0°・下家−90°・対面180°・上家90°）。まとまりの外枠（`.rot-box`）に回転後の寸法を与えるので、回転しても周りと重ならない。
- 牌の大きさ：河の牌の幅 `--rw` を卓の幅から決める（卓の幅＝外側の手牌2本＋左右の河3行＋中央6枚）。iPhone縦で約20px（320px）〜28px（430px）。タブレット横は高さにも合わせ、タブレット縦は最大40px。
- 席の要素（`.panel.seat-N`）は `display: contents` で、子（名札・手牌・面子・河）を卓のグリッドへ直接配置する（DOM上は席ごとにまとまる）。
- 計算（河の行・卓の大きさ・席の向き）は純粋関数 `src/ui/table-layout.js` に分離し、単体テスト `tests/table-layout.test.js`。

## 3. 河の6枚折り返しとリーチ宣言牌
- **自分・対面**：6枚で1行。1〜6・7〜12・13〜18、19枚目以降は4行目以降（卓が縦に伸びる）。行は卓の中央に近い順。対面は180°。
- **左右**：牌は横向き（上家90°・下家−90°）。1〜6・7〜12の後、**13枚目以降は3行目を延長**（実際の麻雀と同じ）。横幅の限られた縦画面で4行目を足すと牌を大幅に縮める必要があるため。延長は、まずその席の右手側の角（上家は左下、下家は右上）の外側の列へ入り、入りきらない分だけ卓の中央を縦に伸ばす（数学Ⅰの通常の局では中央は伸びない）。
- 牌の間は 0px（隣と密着）。牌を箱で囲まない。影・余白を付けない。
- **リーチ宣言牌**：エンジンの `river[].riichi` の物理牌IDの牌だけを、席の向きからさらに90°（実際の卓と同じく左回り）回転。回転後の幅（牌の高さ）を左右の余白で確保し、隣と重ならない。行の折り返しは宣言牌を含めて6枚単位。宣言牌がチー・ポンされた場合は河から消える（次の牌を横にする規則は今回追加していない）。
- 最新の打牌は金色の枠、宣言待ちの牌は赤い枠（従来どおり）。

## 4. 公開面子
- **自分**：手牌の右側に同じ列で並べる（`.hand-row`：手牌 → 少しの間 → 面子）。面子ごとに枠でまとまり、2面子の間に区切り。面子の牌は手牌の0.8倍（手牌の牌幅・タップ判定・2回タップ・長押し並べ替え・自動整列は変更なし）。鳴くと手牌が3枚減るので、9枚分の幅に収まる。
- **他家**：その席の右手側の角（対面は左上、下家は右上、上家は左下）に、その席の向きで置く。牌は河の0.9倍。取得牌の印・`data-claimed`（演出の発光の対象）は従来どおり。

## 5. 名札・卓中央の局情報・上部・ガイド/設定
- 卓中央：数学Ⅰ／Ⅱ、局名（東1局など）、連荘（あるとき）、残り山牌。**親は各席の名札の「親」**で示す（重複表示なし）。すべてエンジン・試合の公開情報。
- 名札（中央の四辺）：名前・点数・親・リーチ（点棒の形。読み上げ用に「リーチ」の文字）・鳴き。左右は縦書き。手番の人の名札は金色。席名（上家など）は名札の `title` と、宣言時の操作バー「上家 ○○ の打牌」に残す。
- 上部はロゴ（数雀 Ver.）だけ。スマホ横では上部を省略。
- **ガイド・設定は下部**：手牌の下の道具の列の右端（チー自動・ポン自動・自動整列・ヒントの右）。高さ36px以上。
- **実況（「○○が△△を捨てました」等）の表示行と生成関数を削除**。ゲームのイベント・効果音・リーチ/和了の演出・カットイン・得点処理は削除していない。宣言者の席の発光は、他家は名札、自分は手牌の欄（従来どおり）。

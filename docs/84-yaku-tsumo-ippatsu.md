# 数雀｜役の追加：門前ツモ・一発（エンジン 0.7.0）

## 1. 仕様（決定済み）

| 役 | 加点 | 成立の条件 | 付けない場合 |
|---|---|---|---|
| **門前ツモ** | +1点 | 門前（公開面子なし。暗カンだけの手は門前）でツモ和了したとき。嶺上ツモも含む | ポン・チーをした手、ロン、役満 |
| **一発** | +1点 | 一発の窓が開いている間の和了（下記）。リーチの加点とは別に数える | 役満 |

一発の窓（天鳳式）：

- **開く**：リーチの宣言で開く。
- **閉じる**：その席の次のツモ（通常ツモ・嶺上ツモのどちらか早い方）が、和了せずに終わった時点で閉じる。リーチの後はツモ切りだけなので、実際にはその席が次に打牌した時点になる。
- **一発になる和了**：
  - その次のツモでのツモ和了
  - 窓が開いている間の、他家の打牌へのロン（いつでも）
- **閉じないもの**：他家のポン・チー・カンでは閉じない。
- **見逃し**：リーチ後のロンの見逃しは、既存のフリテンの規則どおりで、別の扱いはしない。

その他の扱い：

- **重なり**：リーチ・一発・門前ツモは同時に成立する。リーチ一発ツモなら、加点は合計で +3点になる。
- **有効なルール**：ルールセット 1・2 で常に有効（リーチの規則の有無には紐付けない）。
  - 従来ルール（ルールセット 0）の局には付けない。過去の再現 URL の点は変わらない。

## 2. 実装

- `src/engine/game.js` の `_endWin` で、リーチの加点（`_withRiichi`）と同じ流儀で `_withTsumoIppatsu` を通す。
  - 役の一覧に「門前ツモ」「一発」を加える（`id` は `menzen-tsumo`・`ippatsu`）。
  - 基本点に加点する。ドラの加点は、その後に今までどおり行う。
  - 和了の解析には `menzenTsumo`・`menzenTsumoBonus`・`ippatsu`・`ippatsuBonus` を残す。
- **一発の判定（`ippatsuOpen(seat)`）は、記録（`events`）だけから決める。**
  - 判定の式：最後のリーチの記録の後に、その席の打牌が宣言牌の1枚だけかどうか。
  - 状態を新しく持たないので、牌譜の再生（記録された行動を当て直す）で必ず同じ結果になる。
  - `stateDigest` の項目は変えていない。和了の結果（`result`）は digest に入っているので、点の違いは検出される。
- **加点の値**：`config.js` の `menzenTsumoBonus: 1`・`ippatsuBonus: 1`。
- **和了の可否・AI の判断は変えない。**
  - `tsumoAnalysis`・`ronAnalysis` は加点を含まない。加点は和了の確定のときだけ足す。
  - キャラクター AI の期待値にも、門前ツモ・一発は見込まない（今回は方針を変えない）。
- **画面**
  - 局の結果・振り返りの役の一覧に、そのまま出る。
  - ガイド（ルール）に「一発」「門前ツモ」を加えた。従来あった「一発はありません」は削除した。

## 3. 版と、保存済みの牌譜

- **版を上げた**：エンジン `0.6.0 → 0.7.0`（和了の点が変わるため）、画面 `0.7.0 → 0.7.1`。
  - オンライン対戦は、部屋の版（`appVersion`）が違う人が入れないので、点の数え方の違う端末が同じ部屋で打つことはない。
- **保存済みの牌譜（エンジン 0.6.0）は、これまでどおり読める。**
  - 再生の `Game` を `tsumoIppatsu: false`（追加前の数え方）で作る。
  - 新しく記録する牌譜は 0.7.0 で、追加後の数え方になる。
  - 古い版の牌譜は読む・振り返るだけで、書き足しはしない。
- **オンライン対戦**：点はホストのエンジンが計算して配信する（役の一覧も和了の解析ごと配信）ので、追加の通信はない。

## 4. 試験（`tests/tsumo-ippatsu.test.js` ほか）

- **AI 4人の対局（数学Ⅰ・Ⅱ 各30局）の全和了**
  - 門前ツモ・一発が、定義どおり（記録から別に求めた一発の窓・門前）に付く。
  - 同じ行動を「追加前の数え方」で当て直すと、局の進行は同じで、点の差は一発＋門前ツモの分だけになる。
  - 次の場面が実際に起きていることを確かめる：一発ツモ・一発ロン・リーチ一発ツモ（+3）・他家の鳴きの後の一発・リーチしたが一発なし。
- **一発の窓**（記録の列で）：
  - 宣言の直後は開いている。
  - 他家の打牌・ポン・チー・カンでは閉じない。
  - 次のツモの時点では開いている。
  - そのツモを和了せずに打牌すると閉じる。
- **付けない場合**：役満・従来ルール・追加前の数え方には付けない。ロンに門前ツモは付かない。ルールセット 1 では有効。
- **ポン・チーをした手のツモ**：門前ツモが付かない。
- **牌譜**
  - 新しい版の記録は再生（digest・結果・精算）が一致する。
  - 0.6.0 の記録は、追加前の数え方で再生できる。
  - 同じ記録を版を偽って 0.7.0 として読むと拒否される（版で数え方を分けていることの確認）。
- **既存の試験の更新**：門前のツモ和了の点が +1 になる2件（初心者の部屋 5-C・嶺上ツモ）と、版の表示（画面 0.7.1・エンジン 0.7.0）。

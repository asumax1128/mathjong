## 1. コンセプト
三角関数の値から、**関数牌 + 角度牌 + 結果牌**の正しい3枚組（面子）を作る4人対戦の数学麻雀。数学知識を攻撃（和了）と守備（危険牌推定）の両方に使うことを目指す。完成形が数学的に正しいことは必須。

例: [sin] [30°] [=1/2] は成立。 [tan] [90°] [任意の結果] は成立しない。

## 2. 現行プロトタイプ
- **人数**: 4人。
- **手牌**: 配牌8枚。通常は1枚ツモして9枚で和了を判定し、未完成なら1枚捨てる。
- **通常和了**: 牌9枚を、重複利用のない正しい3面子（各3枚）に分割できること。
- **特殊和了**: 指定角度牌9種類を各1枚集める「九角無双」を追加検討中。通常の3面子は不要。
- **チー**: 上家の直前の捨て牌だけを使い、正しい3枚の面子が完成するときのみ可能。完成した面子は公開する。
- **ロン**: 他の3人の捨て牌で和了形を完成できる場合に可能。
- **ツモ**: 自分のツモ牌で和了形を完成できる場合に可能。
- **鳴き後の制約**: 1回でもチーしたら、完成した3面子に少なくとも1つの有効な「役」が必要。**門前（チーなし）は役なしの通常和了可**。
- **ポン**: 導入しない（現段階）。
- **通常のリーチ／独立した = 牌**: 導入しない。代わりに =1/2 のような結果牌を使用。
- **× 牌**: 不採用。積は数式として省略表記する。これは将来の複雑な公式モードの方針。

## 3. 牌の分類
1. 関数牌: sin / cos / tan
2. 角度牌: 0°、30°、45°、60°、90°、120°、135°、150°、180°、210°、225°、240°、270°、300°、315°、330°、360°（17種類を用いた試験構成）
3. 結果牌: =0、=±1、=±1/2、=±1/√2、=±√3/2、=±1/√3、=±√3（13種類）

**重要**: 第3・第4象限を採用する方針は決定済み。**360°自体を含めるかどうかは未決定**。直近のシミュレーションは360°を含む17角度で実施。

現在の主な試験山:
- 関数牌各12枚: 関数36 + 角度17×4=68 + 結果13×4=52 = **156枚**
- 関数牌各16枚: 関数48 + 角度68 + 結果52 = **168枚**
- 各16枚は比較実験を実施した有力候補であり、正式確定ではない。

## 4. 数学的な制約
- tan90°、tan270° は未定義のため面子を作れない。
- 値の表記を統一: 1/√2=√2/2、1/√3=√3/3。正負を区別する。
- 0°・90°・180°・270°・360°は象限の内部ではなく軸上。
- 同じ牌は同じ和了形内でその枚数以上使用できない。
- 別の公式（平方恒等式・加法定理など）を組み立てるモードは長期構想。現在の3枚1面子ルールと混同しない。

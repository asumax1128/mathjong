# 役一覧と役満候補（暫定仕様）

最終整理: 2026-10-24

## 基本原則
**通常和了は正しい三角セットを3組。** チーなしの門前では役がなくても和了できる。チーした場合は3組全体に少なくとも1つの有効役が必要。複合役や得点の合算方法は未確定。

## 役候補

| 役（仮称） | 成立条件 | 仮の評価 | 検証状況 |
|---|---|---|---|
| 三関制覇 | sin・cos・tanを各1組 | 低得点 | シミュレーター実装 |
| 同関一色 | sinのみ／cosのみ／tanのみで3組 | 中得点 | 実装 |
| 余角対 | sinθとcos(90°−θ)の対応する組を含む（有効な非負角） | 中得点 | 実装 |
| 同値三連 | 3面子の結果牌が同一値 | 高得点候補 | 実装・希少 |
| 同角三関 | 同一角度で sin/cos/tan を各1組 | 役満候補 | 実装・希少 |
| 第1象限一色 | 3面子すべての角度が 30/45/60° | 中〜高得点 | 実装 |
| 第2象限一色 | 3面子すべての角度が 120/135/150° | 中〜高得点 | 実装 |
| 第3象限一色 | 3面子すべての角度が 210/225/240° | 中〜高得点 | 実装 |
| 第4象限一色 | 3面子すべての角度が 300/315/330° | 中〜高得点 | 実装 |
| 象限三角揃い | 一つの象限内の3角度を各1回、3面子で使う | 高得点候補 | 実装 |
| 三象限巡り | 相異なる3象限から各1角度 | 中得点 | アイデア段階 |
| 正負対称 | 値が +v と −v の2面子を含む | 中得点 | アイデア段階 |

※「第n象限一色」では同じ角度を3回使ってもよい。一方「象限三角揃い」は3角度を1度ずつ使うので、より厳しい。

## 特殊和了・役満候補

### 九角無双（ユーザー提案の9枚特殊和了）
以下の9角度牌を1枚ずつ:
**0°・30°・45°・60°・90°・120°・135°・150°・180°**

通常面子は不要。通常和了と異なる**9枚の特殊完成形**。プレイヤーの明示的な提案。

### 裏九角無双（追加提案、未承認）
**180°・210°・225°・240°・270°・300°・315°・330°・360°**を1枚ずつ。
360°を採用するかは未決定のため、この役も未確定。

### 三重同式（追加候補）
まったく同じ3枚組を3組つくる。例: [sin, 30°, =1/2] ×3。
同じ角度・同じ結果牌を最低3枚ずつ要する。数学的には成立するが実戦では非常に難しい。

### 同角三関（追加候補）
同じ角度で sin/cos/tan の3組をつくる。ただしtanが未定義の90°/270°では不可能。

### 同値三連（高級役または役満候補）
3組の結果が完全に同じ。計算値の一致を利用する数学的な特殊役。役満とするかは未決定。

## 役の重複と特記事項
- 三関制覇と同角三関は同時成立しうる。
- 象限三角揃いは同じ象限一色も成立する。
- 数学的に役が成立することと、山の枚数で作れること、4人対戦で発生する確率は別。
- 現行シミュレーターの点数は**仮採点**であり正式採用しない。
- 門前役なし和了が強すぎる可能性があるため、役点・チーの判断・得点配分を引き続き検証する。

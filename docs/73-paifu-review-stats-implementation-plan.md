## 決定した段階
### 第1段階：牌譜接続・永続保存（最初の実装PR）
Claude Code Opus 5.5が最新mainから専用ブランチ・Draft PRを作成。
1. PR #37の `docs/51〜57`、`src/engine/paifu.js`、`src/ui/paifu-*.js`、テストを精査。API・schema/バージョン・保存の原子性・ハッシュ・Private API・session契約を最新main・ruleset2・1/4/8局・5点供託・四家立直・アガリやめと照合。
2. 可能な範囲で再利用し、最新mainへ最小の必要ファイルを選択移植。旧PRを丸ごとマージしない。
3. **通常対局の実行された行動だけ**、開始→各局→打牌/鳴き/見送り/ロン・ツモ/リーチ→精算→終了/途中退出を記録。セッション世代・Game参照・before/after・AI/自動パスのsourceを正しく扱う。選択やヒント操作は牌譜の行動にしない。
4. IndexedDBへ保存。保存失敗/容量不足/プライベートモード/複数タブ/BFCache時でもゲーム続行を最優先。ゲーム本体のRNGを消費しない。録画ができなければ明確に「記録されません」と示し、完成牌譜を偽造しない。
5. 安全な最小UI：履歴件数、保存中/成功/失敗の状態表示と、履歴にアクセスできる入口の検討。ただし**第1段階で詳細な振り返り・統計画面は作らない**。
6. 記録の再検証・読込・破損拒否、上限・容量制限・削除、端末ローカル保存と誤認されない説明、履歴移行/既存ローカル保存キー非干渉。
7. 通常対局だけ対象。初心者の部屋、卒業試験、研究用固定山、旧URL、旧ルール記録との混入を防ぐ。旧ルール履歴は版を保持して表示対象判定し、再生不能なら安全に理由表示。
8. 既存全単体/ブラウザE2E/CI、400点/供託0/牌数・現行ruleset2・全12AI・2タップ/長押し/聴牌サポートを回帰。**mainマージ/Pages公開なし**。CodexのHEAD固定監査後にディレクター判断、iPhone実機受入。

### 第2段階：振り返り画面（第1段階正式受入後の別PR）
- 自分の端末に保存された牌譜を一覧表示：日時、数学Ⅰ/Ⅱ、1/4/8局、順位、最終点数、相手3人、対局完走/途中退出を区別。
- 試合選択→局選択→**1判断ずつ前へ/次へ**、誰の手番か、公開河/副露/親/点数/リーチ/ドラ/手牌、終局結果、得点・供託の変化。画面に「自分の手番で知り得た情報」と「対局終了後の事実」を区別する。
- 最初の公開版は**自分の手牌＋公開情報のみ**を時系列で表示し、他家の非公開牌・未来山・未知牌を公開しない。全員の手牌公開や最善打の分析は別途オーナー承認が必要。
- 復元エンジンは記録された選択を再生し、各段階の不変条件/ハッシュを検証。AIに再判断させない。破損/ルール版非対応/途中記録は適切にラベル表示。
- iPhone縦の操作を最優先、既存の卓UIや開始画面への戻り・操作バーと衝突しない。

### 第3段階：戦績機能（第2段階の独立監査後、別PR）
- 自端末に保存された**完走済み**の通常対局を対象：試合数、順位1〜4の回数/比率、平均順位、平均最終点数、ロン/ツモ和了回数、放銃、リーチ、流局などを信頼できる牌譜から導出。記録が欠けた指標は非表示/対象不足と明記。
- 数学Ⅰ/Ⅱ、1/4/8局、対戦相手や難易度などの条件別フィルター。分母と対象条件を表示し、1局と8局を混ぜて公平な強さ比較をしない。
- 履歴0件時の説明、保存失敗の注意、削除（個別/全件）と端末内のみの説明。既存設定/初心者進捗/過去再現URLを消さない。
- 大会・卒業試験・デバッグ・中断記録は通常戦績へ加算しない。モード別の集計は将来の別仕様。

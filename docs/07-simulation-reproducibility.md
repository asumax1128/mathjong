# シミュレーションの再現性・既知の制約

最終更新: 2026-10-24

## このリポジトリでの記録の位置づけ
- [シミュレーション履歴](04-simulation-history.md)は、会話中に報告された数値の**履歴**。
- 数学的に作れる面子、役を含む完成形の件数、実戦での出現率は**別の量**。
- 「各16枚のほうが速い」「戦略性が高い」などの結論は、僅差の結果だけでは確定しない。
- 検証で使用された旧版の簡易AIは、人間の守備や読み、フリテン、点棒移動等を扱っていない。

## 旧版コードの主要ロジック（再検証必須）
1. 牌は関数3種、角度17種、結果13種を番号管理。角度ごとに正しい関数／値の3枚組を列挙。
2. 関数は各12枚または16枚、その他は各4枚。
3. 4人に8枚ずつ配布、1枚ツモして9枚なら和了判定、未完成なら打牌。
4. 他家の捨て牌は誰からでもロン可。上家の打牌だけチー可。
5. チー後は役必須、門前は役なしでも通常和了可。
6. AIはヒューリスティック（完成面子と1牌待ちを高評価する貪欲法）であり、最適探索ではない。
7. 表・裏九角無双の判定は追加試作品であり、実際に九角を狙うAIは未実装。
8. 象限役・三重同式等の一部は後付けで関数を差し替える試作方式。

## 既知の設計・実装確認事項
- **チーによる手番処理**: 通常手番に対する鳴きの割り込み、公開面子数、残り手牌数、捨て牌後の手番を独立したテストで検証する。
- **和了形探索の打切り**: 旧版は一部の和了候補探索を最大30件で打ち切る。最初の30形に役がないが別形に役がある場合の見落としがあり得る。役のある和了を完全探索する実装へ変更する。
- **同じ式3組**: 同一の関数・角度・結果それぞれ3枚を要求する（牌残数チェック必須）。
- **九角無双**: 角度9種類のみを使用する特殊形であり、通常の3面子探索だけでは判定できない。
- **和了率と決着率**: 「誰かが和了した局の割合」と「各AIの勝率」を混同しない。
- **平均得点**: 会話内で報告した2.805/2.790は、流局0を含む局当たり平均仮得点。
- **公平な比較**: 共通乱数やプレイヤー座席のローテーション、独立シード、多数局でのばらつきを確認すること。

## 実験の再実行に必要な情報
- GitHubの `scripts/` にソースが格納された場合、ファイル内のコメント、実行コマンド、乱数シード、実行環境を参照。
- 過去の代表的な対戦試験は各条件2,500局、シードは10000起点として実行された。
- 旧モデルの数字はアーカイブとして残す。改修後のコードで異なる結果が出た場合、旧値を消さずに**モデルを区別して**報告する。

## 次に作るテスト
1. 49種の三角セットが値表と一致すること。
2. 168枚山で各関数16枚、角度・結果各4枚であること。
3. チー直後の手牌数が適正なこと。
4. 役あり/役なしの和了可否を完全探索で確認すること。
5. 九角無双・裏九角無双と通常和了の例を網羅すること。
6. AIごとに数万局以上を回して勝率とばらつきを比較すること。

現段階のシミュレーションは**企画選択の参考材料**であり、競技性が実証済みの正式な品質保証ではない。

# MATHJONG Ver.0.3-B 実装記録 — 2段階ヒント・数式のカラー表示

作成: 2026-10-25 ／ 基準: Ver.0.3-A（main `85a7250d5e2b627d864502bddd0d873356e198e1`）／ ブランチ `feature/v0.3-b-hints`
今回はヒント機能だけ。ルール・役判定・得点・AI・進行は変更しない。親制度・関数ドラは未着手。

## 1. 基本理念
数学的に成立する数式を発見・確認できるが、麻雀の最善手（捨て牌・待ち・戦略）は教えない。
数式の一覧・表示順・初期選択は、角度の小さい順 → sin・cos・tan の順だけで決め、役の点数・AI の評価は使わない。

## 2. 第1段階（発見）— ヒントを開いた直後
- 完成している数式の通り数（手牌内。鳴いた手では「手牌内の」）
- あと1枚で完成する組み合わせの件数（従来どおり）
- 公開済み：数式面子 n組・刻子 n組（鳴いた手のみ）
- 狙える役（近い順）・役の得点・不足枚数（従来どおり）
- 「数式を確認する」ボタン（完成数式が0通りなら出さない）
- 出さないもの：具体的な式、手牌の枠、待ち牌、おすすめの捨て牌。

## 3. 第2段階（確認）— 「数式を確認する」
第1段階の情報に加えて：
- 同時に使える数式面子の最大組数（手牌全体）
- 完成数式の全候補の一覧（番号付き。同じ式を複数組作れるときは「×n組」）
- 手牌の色枠（最大2色）：1通りなら黄色。2通り以上なら第1数式＝赤、第2数式＝青。
  - 一覧の各行の「赤」「青」ボタンで表示する数式を選ぶ（同じ式をもう一方に選ぶと入れ替え）。
  - 「2式／赤だけ／青だけ」で表示を切り替える。
  - 一覧の行は選択中の色で背景を付け、「赤／青」の札と番号でも対応を示す（色だけに頼らない）。
- 共有：選んだ2式を物理牌の重複なしに作れないときは、1組ずつ、できるだけ別の牌を使い、どうしても共有する牌だけ上半分＝赤・下半分＝青の枠にする。「牌を共有するため、同時には使用できません」と、手牌全体の最大組数を併記。

## 4. 数式の整理（`src/engine/formulahint.js`、純粋関数）
- `analyzeFormulas(rules, hand)`：手牌（公開面子は含めない）から、`rules.melds` の `kind === 'formula'` で3種類とも手にあるものを列挙（重複なし、並び順は角度→関数）。各式の組数 `copies`。完成数式だけを対象に組合せ（重複あり）を全探索し、同時最大組数 `max` と、それを実現する組合せ `optimal`（重複なし）を求める。刻子は含めない。三角関数の正誤は `rules.melds`（厳密値で生成）だけに頼る。
- `initialSelection(rules, analysis)`（例外C）：1通りならその式。2通り以上なら異なる2式の組を、①最大組数を実現する組合せに両方含まれる、②重複なしに同時に作れる、③牌を共有、の順で、同じ段階なら並び順で最初の組を選ぶ。
- `assignColors(rules, hand, analysis, sel, { mode, single })`：表示する式を物理牌 id に割り当てる。1種類ならその式を作れるだけの組数を同じ色で。2種類は、両方1組以上ずつ重複なしに作れるなら合計組数が最大（同数なら赤を多く）。同じ種類の牌は id の小さい順に使うので、手牌の並び替えでは色が変わらない。
- `exposedSummary(rules, melds)`：公開面子の数式面子・刻子の組数。

## 5. 状態（`src/ui/app.js`）
| 操作・変化 | 動作 |
|---|---|
| ヒントを開く | 第1段階 |
| 数式を確認する | 第2段階 |
| 表示の切替 | 第2段階のまま（回数は数えない） |
| 打牌・ツモ・チー・ポン（自分の手牌の構成が変わる） | 第1段階へ（ヒントは開いたまま） |
| 並び替え・自動整列 | 段階・表示対象・色を維持（物理牌 id に対応） |
| 他家の打牌・鳴き | 段階を維持。役候補などは更新 |
| ヒントを閉じる | 枠を解除。次に開くと第1段階 |
| 和了・流局 | ヒントを閉じる |
| 次局 | 初期化（閉じた状態・回数 0） |
- 第1段階へ戻す判定は「自分の手牌の構成」＝物理牌 id の集合＋自分の公開面子（`handStateKey`）。表示順は含めない。役候補の再計算は従来どおり公開情報のキー（`hintKey`）で行う。

## 6. 回数
- 発見：ヒントを開いたとき、その手牌の状態で初めてなら1回。
- 確認：「数式を確認する」を押したとき、その手牌の状態で初めてなら1回。
- 値表：従来どおり開くたび。
- 閉じて開き直す・表示の切替では数えない。開いたまま手牌が変わったときの自動表示（第1段階）は数えない（従来の「自動更新では加算しない」を維持）。
- `S.hintsUsed` は3つの合計（互換）。結果画面に「この局のヒント：発見 n回・確認 n回・値表 n回」。得点のペナルティはなし。

## 7. 画面
- 枠は牌の外側の `::before`（`pointer-events: none`）。牌の大きさ・中身・タップ・長押しドラッグに影響しない。2色はグラデーションをマスクで枠の形にして上下に分ける。
- 一覧は最大高さ 11.5em でスクロール。320〜430px で横スクロールなし（E2E で確認）。

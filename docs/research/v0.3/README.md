## 決定事項と未決定事項

- 数学Ⅰ：0°〜180°の9角度種（各4枚）。関数牌sin/cos/tan各12枚（36枚）、結果13種各4枚（52枚）、合計124枚が有力案。
- 数学Ⅱ：0〜2πの17角度種（各4枚）、関数牌各16枚、結果13種各4枚、合計168枚。
- 弧度法は数学Ⅱのみ、数学Ⅰは度数法。内部の厳密値は変えない。
- 数式面子＋同種刻子の混合和了を認める。門前は役なし可、鳴き後は役必須。ポンを導入、ロン＞ポン＞チー。
- 数式系の役候補ヒントを刻子系より優先。ただし「あと何枚」は正確に表示。
- 新役は対々和、三暗刻、正弦一色、余弦一色、正接一色。点数は暫定。
- 数式3面子向け従来役、混合鳴き和了の扱いは設計中。
- 9枚和了（3面子）が暫定有力、11枚和了（3面子＋雀頭）も保留比較。
- スマホは従来UIを保持。タブレット・PC横長画面のみ麻雀卓型に変更。

## 追加80,000局のポンAI比較

数学Ⅰ・124枚・9枚和了。独立Node.js試作モデル、各ポリシー20,000局・同じ山seed。チー選択は10%の簡易AI。**実MATHJONGのゲームエンジンではない。**

役見込みポン：他の2刻子の不足牌2枚以下・公開牌を控除した未見牌から供給可能、2回目のポンは残る1刻子があと1枚以下なら実行。

**結論は暫定**：役見込みポンは無条件に近いポンと比べ対局速度を保ちつつ、対々和908/20,000局を達成。少なくとも数式1組を含む和了は19,058/20,000局。正弦/余弦/正接一色は通常AIの80,000局で計1回のみ（正接一色、積極ポン条件）。専用の一色狙いAIで追加検証が必要。

### 限界

- 誰か一人の和了率であり、各プレイヤー個人の勝率ではない。
- 4人が同一戦略。チー・打牌・ロン時三暗刻判定は簡略化。
- ポン導入効果を本体エンジンに外挿できない。11枚制も未確定。
- 既存数式系役は数式3組にのみ適用した試作ルール。
- 生数値は同フォルダの `pon-results.json` に格納。

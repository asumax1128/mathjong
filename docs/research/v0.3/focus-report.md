# MATHJONG Ver.0.3 — 関数一色を狙うAI 80,000局の追加検証

日付：2026-10-25。**ゲーム本体ではない独立試作モデル**。数学Ⅰ（124枚、配牌8＋ツモ1＝9枚和了）、数式26種類、同種刻子25種類、役成立見込みを評価するポンAIを基準とする。

## 条件
- 4人AI、seed 201111〜221110を各条件共通使用。
- AIのうち**席0だけ**一色専用戦略へ変更。他3人は役見込みポンAIのまま。
- 8枚の初期手牌で最多の関数牌がsin/cos/tanのどれかを調べ、枚数が閾値以上なら**その関数一色を狙う**。
- 一色狙い中はターゲット以外の牌を先に捨て、ターゲットがポン可能ならポンする（最大公開2組）。門前で別役を偶然和了できれば和了は許可。
- 閾値未満の配牌なら通常の役見込みポンAIに戻る。4条件各20,000局、合計80,000局。
- 一色成立は**9枚全て同じ関数牌**。各関数12枚の山。数式系・通常刻子の完成形はゲームとして認める。
- 同seedでも打牌判断が変わるため、その後の各プレイヤーの取得牌は分岐する。AIは試作の貪欲評価、チーは確率10%の簡略判断。

### 一色を狙う対象局での結果

- 2枚以上条件：一色成功18/9,991対象局 = **0.180%**、対象局での席0和了は233/9,991 = **2.33%**。
- 3枚以上条件：一色成功12/2,056対象局 = **0.584%**、対象局での席0和了は91/2,056 = **4.43%**。
- 4枚以上条件：一色成功5/193対象局 = **2.59%**、対象局での席0和了は17/193 = **8.81%**（標本小、推定不安定）。
- 基準戦略（狙わない）：席0和了は5,440/20,000 = **27.2%**。一色狙い開始条件を2枚まで緩めると14.5%、3枚なら24.1%、4枚なら26.9%へ低下。
- ほかの3席が通常戦略で偶然一色を完成させる例もあるため、全員合計の一色件数は2枚閾値19、3枚閾値12、4枚閾値5。

## 解釈

9枚同関数の役満は確かに**達成可能**だが、この一色専用AIでは現実的な勝率を大きく下げる。関数牌を各12枚に減らしても「役満が全く成立しない」とは言えない。一方で、積極的に狙わせると従来の数式ゲームから逸れるため、通常AIが一色を優先目標にする設計は不適切。

**推奨**：正弦・余弦・正接一色は隠し目標的な稀少役満として維持。数式中心の役ヒントを優先し、一色は自然に3〜4枚集まった局面で候補を示す程度に留め、役満狙いのための強制切り替えはしない。出現率を最終確定するには公式エンジンでAI戦略・他家がポンする確率などを再評価。

## 統計上の注意

- 役満件数は5〜18件と少なく、条件ごとの成功率に大きな不確実性がある。
- 同じ配牌のターゲット対象に限った基準AIの条件付き勝率はここでは算出していない。全局の27.2%との比較は戦略全体の影響を表し、同一配牌下での因果効果を正確に推定しない。
- 閾値2/3/4の一色狙いは**同一の閾値政策を試行**したもので、上手な人間の一色選択の上限ではない。
- 未実装の11枚制は扱わない。9枚特殊役を11枚制へ持ち込む条件は別途設計が必要。
- 詳細数値は `focus-results.json` に格納。計測スクリプトはローカル別途保存済みでGitHubへのソース収録は未完了。

## 次の実装前検証

- 11枚制では特殊一色の定義変更が必要。現段階で役満条件を緩和しない。
- 正式ゲームエンジンで、ポン後の役付き和了が本当に成立するか検証する。

# Ver.0.3：9枚制 vs 11枚制 比較（2026-10-25）

**対象：独立した簡易AI試作モデル。正式MATHJONGエンジンではない。**
12条件×各10,000局＝**120,000局**、seed=321000〜330999。数値は [9vs11-results.csv](9vs11-results.csv) 参照。

## 共通条件
- 数学Ⅰ12枚案：関数各12、角度9種×4、値13種×4＝124枚。数学Ⅰ16枚案：関数各16＝136枚。数学Ⅱ：関数各16、角度17種＝168枚。
- 9枚制＝数式または刻子の3面子。11枚制＝同じ3面子＋任意の同種2枚の雀頭。数式面子と刻子の混合を認める。
- 4人とも同じ簡易AI（数式寄りの貪欲打牌、11枚制のみ雀頭の保持を考慮）。チーは可能時10%で宣言する簡易判断。
- ポン「なし」と「役見込み」を比較。後者はポン後の対々和に必要な残り牌が2枚以内、2回目ポンなら1枚以内かつ見えている牌を考慮した基準。
- ロン＞ポン＞チー。鳴き後は成立役が必要。混合鳴きの役は今回用意しない。三暗刻のロン判定は簡易。
- 9枚専用の九角無双など特殊和了は**双方で無効**にして比較。11枚特殊和了の定義は未決定。
- 同seedで山をシャッフルするが、初期配牌枚数が異なるので同じプレイ局面ではない。意思決定後の山の消費順も分岐する。

## 主要結果（ポン＝役見込み）

|モード|9枚制 和了率|11枚制 和了率|9枚 平均打牌|11枚 平均打牌|9枚→11枚 数式3面子率|9枚→11枚 刻子3面子率|
|---|---:|---:|---:|---:|---:|---:|
|数学Ⅰ・124枚|99.82%|99.79%|25.59|23.18|72.2%→69.7%|4.1%→5.8%|
|数学Ⅰ・136枚|99.77%|99.86%|25.68|21.95|61.5%→57.7%|8.2%→9.7%|
|数学Ⅱ・168枚|99.97%|99.92%|26.73|25.66|76.8%→75.7%|2.4%→3.3%|

**今回の試作では、11枚制が全3構成で9枚制より早く決着した。** 数学Ⅰ124枚では平均2.40打牌短縮。ポンなしでも11枚制が速く、ポンだけが理由ではない。11枚制の追加手牌が選択肢を増やす影響があり得るが、その因果は未証明。

9枚制と11枚制の「誰かが和了する確率」はどちらも約99.7〜100%で差が小さい。差の中心は、平均打牌回数と和了形の内訳。

数学Ⅰの関数各12枚は各16枚に比べ、数式3面子の和了比率が高い（124枚ポン可9枚72.2%、136枚ポン可9枚61.5%）。**124枚案は有力**。

## 推奨
- **9枚制を当面の第一候補**とする。ただし理由は難易度やゲーム速度ではなく、既存ルールの継続、画面の簡潔さ、数式3面子の比率が少し高いこと。
- 11枚制は「必ず難しくなる」「長引く」という仮説を採用しない。逆の結果が出ているため正式AI・実エンジンで再検証。
- 11枚制の雀頭の教育的意味、九角無双・一色役満・三暗刻の扱い、スマホの視認性を仕様確定してから最終決定。
- 現行エンジンを変更せず、Ver.0.3-Aのルール試作を別ブランチで実装してから公平比較を再実施する。

## 制約
- この比較は本編エンジン・正式AIではない。チー10%・局面評価の単純化があり、強いAIや人間対戦の数値ではない。
- 9枚制と11枚制は同じルールを実装したとは限らず、11枚制は雀頭評価を追加している。モデル選択に影響する。
- 関数一色の成立条件は9枚／11枚それぞれ全枚数を同関数としている。11枚制の役定義は未承認。
- 平均打牌は4人合計の打牌判断回数（ポン後打牌を含む）。和了率は個々のAIの勝率ではない。
- **再現用ソースはまだGitHub上に収録できていない**。実行用ソースと全集計JSONは会話内の成果物として提供し、GitHubへの追加保存は別工程とする。

# リーチ後のオートツモ切り

> 状態：**Draft PR（未マージ・未公開）**、ブランチ `feature/riichi-auto-tsumogiri`（基準：main `7892a85`）。テスト専用サイトは作らない。mainマージ・Pages公開はディレクターの確認後。

## 仕様
- リーチ中だけ、手牌の下の道具の列に「オートツモ切り ON/OFF」を出す（リーチ中は鳴けないので、チー・ポンの自動パスの切替の位置に置き換える。幅は増えない）。既定は **OFF**。設定は局ごとで保存しない（リーチは局の終わりまで）。新しい局・再戦・タイトル／相手選択へ戻ると OFF。
- **ON**：自分の通常ツモの後、ツモ和了できなければ、ツモ牌を自動で捨てる（AI の手番と同じ間をおく）。
- **止まる場面**（自動では何もしない）：
  - ツモ和了できる → 「ツモ」「ツモ切り（見送り）」を本人が選ぶ。状態欄に「自動ツモ切りは停止中」。
  - 他家の打牌でロンできる → 「ロン」「ロンしない」を本人が選ぶ（オートツモ切りは宣言に一切応答しない）。
- 見送った後も ON のまま。フリテンは既存の規則のまま（エンジンが判定）。
  - ロンの見送り → リーチ後の見逃し（この局の終わりまでロン不可）。
  - ツモの見送り＝和了の牌を捨てる → 捨て牌のフリテン。
- **OFF** に切り替えると、予約していた自動操作を取り消し、手動のツモ切りに戻る。OFF のときの進行・判定は従来と同じ。
- リーチ中の打牌はツモ牌だけ（エンジンが拒否する従来の規則のまま）。
- 数学Ⅱの通常ツモ24回・流局、王牌・ドラ・暗カン（リーチ中はできない）・AI は変更なし。

## 実装
- `src/ui/auto-tsumogiri.js`：自動で捨ててよいかの判定（純粋関数）。自分の手番・リーチ中・ツモ直後・ツモ和了できない・設定 ON のときだけ。
- `src/ui/app.js`：
  - `step()` は自分の手番を描画した後に `scheduleAutoTsumogiri()` を呼ぶ。
  - 予約は既存の `S.timer`（`step()` のたびに取り消される）と局面の識別子（`stateKey()`）で1つに限る。実行直前に、局・局面・設定・条件を確かめ直す（手動でツモ切り・ツモ和了・OFF・局の切替のあとは何もしない）。
  - 手牌の並び替え中は待つ（既存の `stepDeferred`）。エンジンが拒否したら OFF にして手動へ戻す。
  - チー・ポンの自動パスとは場面が重ならない（リーチ中は鳴けない。ロンのある宣言はどちらも自動にしない）。
- エンジンは変更していない。
